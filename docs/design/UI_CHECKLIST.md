# InMoment UI 检查清单

更新日期：2026-11-09。

本清单与 [UI 与交互规范](UI_GUIDELINES.md)、[动效规范](MOTION_GUIDELINES.md)、[视觉复查规范](VISUAL_REVIEW_GUIDELINES.md) 配套。每次新增或修改 UI，检查相关入口和共用组件；修改共享颜色、字体或按钮时，检查所有页面。

## 开始前

- [ ] 读取 UI 规范，确认本次界面使用的颜色、字号、间距、控件尺寸与现有组件。
- [ ] 参考图的采用范围与用户要求一致；形状参考保留原配色，外观修改没有删除既有进度、状态反馈或快捷操作。
- [ ] 先确认每个交互入口对应必要动作，静态品牌、标题和说明保持内容语义。
- [ ] 准备隔离测试数据：多个分组、至少 30 条记录、超长标题、多段合成音频、长语音文本、带／不带截图及有／无摘要。
- [ ] 使用模拟响应验证 AI 状态；真实 API、模型运行、真实录音与桌面截图按项目授权执行。
- [ ] 用户现有设置、灵感、音频和截图保持原有位置。

## 颜色与图标

- [ ] 正文为近黑色，白色和中性灰的表面没有整体偏绿。
- [ ] 胶囊和录音展开面板均沿用公共白／灰／绿配色；圆形品牌是独立设计的矢量资产，字形与留白在 28px、放大及缩放后均衡，无裁剪偏移。
- [ ] 各窗口按按钮语义使用对应底色。中性动作叠 `#191919`，删除与红色取消叠 `#B42318`，绿色动作、四角星和绿金品牌按钮叠 `#256D49`。截图的彩色色样按自身颜色叠色，黑白色样使用中性灰。
- [ ] 模态遮罩覆盖原生窗口按钮区域，悬停不产生白色缺口；取消／Esc／关闭后恢复原有颜色与按钮可用状态。
- [ ] 所有可执行的删除／丢弃动作及最终确认采用红色；关闭与普通取消使用中性色。
- [ ] AI 总结、按描述查找、一键整理等按钮在标签前显示同一个单四角星。各入口的四角星线型、面型与按钮文字均为墨绿 `#102719`，禁用时降低强调。
- [ ] 功能图标使用官方 20px 光学 Regular／Filled 独立资源；来源、许可证、逐文件 SHA 与单四角星修改记录完整。
- [ ] 16px 常规图标与 14px 文字居中对齐，间隔 8px；图标大小、线宽和视图框一致。
- [ ] 分别检查点击框、图标框和实际着色轮廓；图标及文字整组居中，非对称形状经实际尺寸人工复查。
- [ ] 聊天剪刀绘制框为 20px、点击框为 36px，与相邻录音／发送图形视觉大小协调，缩放与动效不改变中心。
- [ ] 光学微调默认 0，确有需要时单轴不超过 1 CSS px，两态使用相同校正参考，记录原因；点击框、标签、间距和焦点框不变。
- [ ] 纯图标按钮可通过可访问名称辨认；装饰图标不重复朗读。
- [ ] “更多”、整理结果叉号等纯图标按钮显式水平／垂直居中；图标框与实际底块中心的横纵误差各不超过 1 CSS px，图形光学偏移另按登记值检查。
- [ ] 普通可点击功能图标默认线型，悬停、键盘焦点或持续选中时 180ms 面型自下而上擦入，线型同步退出。持续选中后移开鼠标与焦点仍显示面型，取消选中后检查线型恢复。聊天发送按钮按本表的聊天项检查。
- [ ] 减少动态效果时图标立即切换。普通不可用控件、非交互装饰和非交互品牌 logo 保持静态，录音品牌控制使用专用形变。
- [ ] 文字对比度至少 4.5:1，必要图形和焦点提示至少 3:1。

## 控件和浮框

- [ ] 同组按钮、输入框与选择器高度一致，使用统一内边距，按各自组件规格检查圆角。
- [ ] 常规控件高 40px，紧凑文字控件高 36px；记录列工具栏按专用规则最小高 32px，紧凑图标按钮 32×32px，操作栏按钮和触控目标至少 44×44px。
- [ ] 点击区域覆盖控件且不遮挡相邻控件；按钮标签完整显示。
- [ ] 普通按钮未触发为透明，聊天发送与停止回复为浅绿。悬停、按下与实际选中均叠加 4% 按钮基色。指针移开后，实际选中项持续保留底色。按下缩至 97%，释放后恢复尺寸并按实际状态显示底色。减少动态效果时即时切换底色并保持尺寸。按 [视觉复查规范](VISUAL_REVIEW_GUIDELINES.md#按钮各状态的底块与留白) 核对中性、绿色和红色按钮的像素值。
- [ ] 逐项切换笔记、聊天、分组、列表和设置分类，实际选中项持续显示触发态。帮助、新建、收起等单次动作释放后按指针位置复位。折叠按钮开合后箭头随状态更新，鼠标移开显示透明底。
- [ ] 每个按钮逐状态核对点击框、完整背景边界、内容内边距、外围留白与图文重心；默认透明也按完整悬停底块检查。
- [ ] 普通文字、图文和纯图标按钮底块共用 12px 圆角，较小的按钮按可用尺寸收合圆角。最左栏以 44px 点击框承载圆角 12px 的 36px 底块，核对四边等距和图标重心。聊天发送与停止回复按正圆验收。
- [ ] 默认／悬停／选中／焦点的尺寸、位置、内边距和文字基线不变，边框空间已预留，底块不贴容器边缘或裁掉圆角。
- [ ] 操作按钮的标签或图文组在自身底块内居中。用原尺寸的悬停截图测量，常规文字或图文按钮两端内留白各至少 8 CSS px，同组相邻底块间隔至少 8 CSS px。侧栏和另有规范的紧凑控件按各自规格。导航行、菜单选项与记录行保持公共起线和垂直居中。
- [ ] 鼠标选择与聚焦时无额外描边。Tab 访问按钮有清楚的底部短线，文字链接与折叠入口有下划线，输入框有光标且原边界不变。高对比度模式使用系统焦点色。
- [ ] 分组滚动导航和选择浮框的首项、末项和滚动后的键盘焦点提示可见，文字与图标保持原位。保留默认、悬停、选中和键盘焦点截图。
- [ ] 主窗口折叠入口最小高 32px、行高 24px、上下内边距 4px／左右 8px、宽度 `fit-content`。悬停与按下使用公共灰底，原生标记表达开合并支持键盘操作。
- [ ] 禁用动作无法触发，悬停不改变背景、边框和图标；处理中不会重复提交，反馈位于当前动作附近。
- [ ] 删除使用就近小浮框再次确认；添加到组的浮框可搜索并选择分组。
- [ ] 点击外部和 Escape 能关闭小浮框；Escape／菜单操作后焦点回到触发位置，点击外部后焦点保留在新目标。
- [ ] 浮框与其最终操作按钮在窗口和缩放后都完整可见。
- [ ] 工具栏只有一个“筛选”入口，面板集中放置时间、自定日期、关键词和按描述查找，显示当前分组范围；一键整理留在面板外。
- [ ] 筛选条件点击“应用筛选”后生效，取消／外部关闭保留原条件；触发按钮反映已应用条件，错误日期有就地反馈。
- [ ] 按描述查找进入描述输入流程，键盘、点击外部和 Escape 关闭正常；输入文字不会自动调用 AI。
- [ ] 多选工具栏默认透明。“选择／完成”为居中文字入口，无功能图标。当前模式用触发态灰底表达，删除文字和图标使用危险红色。
- [ ] “选择／完成”最小高 32px，上下内边距 4px、左右各 8px；默认、悬停与选中底块内文字均居中，选择文字使用自身内缩起线。
- [ ] 总选复选框常驻；普通浏览时点击直接进入多选并全选当前列表已显示的可选记录，“选择”进入时为 0 条，“完成”退出并清空。
- [ ] 总选的未选、部分选中、全选三态与记录计数同步；部分态使用 `indeterminate`，点击部分态为全选、点击全选为清空，无独立“全选”按钮。
- [ ] 复选框有独立可访问名称，支持键盘；空结果与处理中正确禁用，多选仍支持分组和删除。

## 基准线与间距

- [ ] 各列标题、工具栏、正文、来源和同级区块沿公共内容起线排列，边界与内边距一致。
- [ ] 同行文字共基线，按钮／输入框／复选框共控件中心；图标与标签的视觉对齐另行复查。
- [ ] 记录列的选择框绘制边为 16px、点击框为 32px；以列左边缘为 0，可见方框左 16／中心 24，搜索文字和多选行标题共用 40px 起线，普通行标题起线为 16px。
- [ ] 记录列搜索框 36px、主页搜索框 40px；筛选／整理与批量动作等宽居中，列宽不超过 160px 时计数独占一行。
- [ ] 记录列顶部内边距 12px；返回按钮点击框与底块 32×32px，完整悬停底块距列顶至少 12px、右缘与分组标题间隔 8px；分组标题起线为 48px，焦点外沿无裁切。
- [ ] 间距沿用 `4 / 8 / 12 / 16 / 24 / 32px`，相同关系使用相同值，按钮两侧留白均衡。
- [ ] 原本共线、等宽或等高的元素在同一缩放环境中误差不超过 1 CSS px；排除取整差异后修正布局。

## 布局与长内容

- [ ] 品牌图标、贯穿窗口的操作栏、底部设置入口保留。
- [ ] InMoment 名称是静态 `span`，无链接、点击、按钮式悬停和 Tab 焦点，标题栏拖动可用；返回分组主页仍使用现有返回按钮。
- [ ] 创建表单收起且分组导航 `scrollTop = 0` 时，分组栏标题区域高 40px、品牌行高 24px；工具区内边距为 `12px 4px 12px`、工具行高 32px、标签行高 24px；导航区内边距 0、首项高 40px、文字行高 24px。以栏顶为 0，三行中心为 20／68／116px，中心距 48／48、行框空白 24／24；与按钮背景间距分开测量。
- [ ] 有效视口不超过 900px 的分组抽屉，标题行间隔 8px、水平内边距 0，分组栏自身左右留白 8px；保留 16px 品牌字号和 32×32px 关闭按钮，InMoment 完整显示。检查 800px 和约 682px 有效视口，纵向中心仍为 20／68／116px。
- [ ] 最左图标栏底部从上到下是问号帮助和设置，均为 44×44px、间隔 6px，设置距栏底 12px。检查原麦克风入口已从点击范围和 Tab 顺序移除。“录音说明”仅从问号按钮打开，图标、提示与可访问名称一致，关闭后焦点回到问号。
- [ ] 桌面布局中分组栏与记录栏等宽，两栏加图标栏约占四分之一至三分之一，详情获得主要空间。
- [ ] 详情模式的搜索、筛选、选择、整理、加载反馈和分页都位于记录列，右侧没有整组列表操作栏；返回分组主页后，原控件恢复到网格上方。
- [ ] 详情与主页切换复用同一份控件，搜索内容、焦点和选中文字保留；多选范围及未保存的详情编辑不因移动控件而改变。
- [ ] 窄窗口和高缩放下记录列与操作入口可达，紧凑标签完整显示；顶部内容超过列高 60% 时自身滚动，记录列表仍有独立滚动空间。
- [ ] 200% 缩放下从导航抽屉切换未保存记录、灵感云、设置或聊天后，抽屉与遮罩完成退场，目标页面控件可操作；同页刷新不额外收起。
- [ ] 控件换列时旧浮框关闭；重新打开的筛选、分组和删除浮框靠近当前触发按钮，关闭后焦点不跳回旧位置。
- [ ] 记录列表仅显示一行居中的标题；长标题省略，详情中能查看全文。
- [ ] 网格卡片和整理结果中的标题、简要信息各占一行，卡片尺寸一致。
- [ ] 长列表的记录行不挤压；各列正常滚动，没有互相覆盖。
- [ ] 详情标题与正文可自然换行，编辑框和保存控件不会被裁切。
- [ ] 笔记标题、正文和录音浮窗的「保留的文字」通过光标或选区显示编辑焦点。点击与 Tab 进入时，原有边框、底色和几何尺寸保持一致，高对比度模式可辨认键盘焦点。
- [ ] 标题重命名显示保存和取消，Enter 保存、Escape 取消；未保存修改按现有确认规则处理，按钮与编辑框相邻。
- [ ] 空区块不占位；两条分割线之间存在实际内容，或合并为一处间隔。
- [ ] 笔记、聊天、偏好设置与恢复录音共用外壳。标题栏高度等于左侧栏宽度，两栏同色且无交界分割线，内容区左上圆角保持原位。切页、普通窗口、最大化和 125%／150% 缩放时检查原生窗口按钮与可拖动区域。
- [ ] 左侧导航、笔记工具栏、聊天、设置、录音浮窗和截图工具遵守按钮三态。逐状态比对按钮前景、底块和内容中心，覆盖纯图标、纯文字及图文按钮。
- [ ] 详情滚动条贴工作区右边缘，阅读起线、阅读宽度和内边距保持一致；没有双滚动条。
- [ ] 设置分类在宽窗位于左侧，窄窗位于顶部；切换分类保留表单修改，校验可定位到其它分类的错误字段。
- [ ] 设置内容与底部保存栏分处独立布局行，长反馈和缩放时底栏不覆盖表单；点击和 Enter 提交正常。
- [ ] 截图保持比例，来源与操作对齐；标题下只保留“打开所在文件夹”。
- [ ] 来源标签透明无灰底，“回到原窗口”在同一信息行，窄视口自然换行且行间有间距。
- [ ] 背景信息集中展示来源应用、窗口标题、网址和来源窗口截图。选区截图独立显示；两类截图均能预览和定位自己的原图。长网址最多显示两行，提示与可访问名称保留完整网址。

## 笔记和录音

- [ ] 启动显示「纸页起笔」，放大的无底色 i 与标题同排。新建可直接进入编辑，最多三条最近笔记按最后编辑时间排序，点击打开对应笔记。展开的分组列、笔记列与主窗口聊天历史栏等宽。「分组」和「笔记」标签同为 18 CSS px、字重 400，起线、基线与内边距一致，两列搜索框同宽同高。「未分类」与设置按钮同行。
- [ ] 分组列可用鼠标和键盘收起，按钮显示三条横线与向左箭头。收起后与左操作栏等宽，箭头向右，展开恢复原分组、搜索和滚动位置。验证切页、快速反向、窄窗口抽屉和减少动态效果。
- [ ] 启动时笔记列直接显示「全部笔记」，首帧达到完整列宽。切组只更新原列内容，窄窗口从正文返回时直接显示列表。检查快速切组和减少动态效果下的列边界、焦点与列表内容。
- [ ] 分组树检查新建子组、搜索、移动、复制粘贴、多选、合并与两种删除。删除组保留内容时验证上移到父级，含内容删除时验证其他分组的独立笔记。笔记复制验证修改副本时原文、附件、原录音保留。
- [ ] 笔记搜索在列表最上方。空新建在离开与重启后无新增记录，第一次输入或添加附件才落盘。右键重命名打开正文并选中标题。全选按当前搜索范围，AI 分类仅从「未分类」入口启动。
- [ ] 新建或已有笔记在标题按 Enter 后，光标落在正文起点，随后的文字插在原内容之前。中文输入法用 Enter 确认候选时焦点留在标题，结束组词后再按 Enter 进入正文。正文 Enter 仍能换行。
- [ ] 单条与分组分别测试 PDF、Markdown、合并、分文件、附件、取消及输出失败。组导出包含子组笔记，带中文名称和长正文的 PDF 可读。
- [ ] 笔记正文检查三级标题与正文切换、项目符号和编号列表、加粗／斜体／下划线、字号、颜色及常用符号。分别用光标、选区、键盘和鼠标操作，检查菜单关闭与返回编辑焦点、普通粘贴、输入法、撤销、自动保存及重新打开后的格式。
- [ ] 段落菜单以「• 项目符号列表」和「1. 编号列表」预览正文列表标记，核对选择后实际应用的样式和当前项勾选。
- [ ] 图片下方的空列表项按 Backspace 后退出该项，保留上方图片和后续内容。对留下的空行再次退格可单独移除该行。检查标题或文字前的空行、连续空行、正文末尾、编号及项目符号列表、主动选图删除、撤销与重做。
- [ ] 按住拖选时不出现格式浮层，松手或结束键盘选择后等 1 秒。检查单行与多行选区，核对浮层中心对准可见首行中心并留 8px。分别验证正文密集、靠左右边界限位、顶部空间不足改置下方。检查取消选区、快速重选、Escape、切换笔记、光标状态下手动打开、滚动和缩放，确认原选区和正文位置稳定。

常规本地检查：

```powershell
pnpm test
pnpm check
pnpm ui:audit
```

`pnpm ui:audit` 运行 `scripts/notes-audit.cjs`，覆盖启动、编辑和自动保存、搜索、分组、附件粘贴、本地音视频播放、背景信息弹窗与原图预览、录音移除、键盘焦点和重启后保留。

运行需要 Electron 和 Playwright。Playwright 不在默认依赖路径时，用 `INMOMENT_PLAYWRIGHT` 指定其安装路径。检查使用隔离数据和禁用网络的环境，窗口截图与 `report.json` 保存在 `.local/notes-review/run-*/`。

`pnpm ui:chat-audit` 检查聊天输入与预览。旧版资料库截图和交互烟测脚本为 `scripts/ui-audit.cjs` 和 `scripts/ux-smoke.cjs`，依赖旧版收件箱和灵感云界面。

`tests/ui-icons.test.cjs` 检查图标挂载、动态更新和资源来源完整性，`tests/ui-motion.test.cjs` 检查快速导航、中断、重复展开／收起、弹窗与侧栏重开和减少动态效果。这些检查包含在 `pnpm test` 中。动效视觉验收另看起始、中间和结束画面，核对来源位置、擦换边界、焦点和残留节点。

按 [视觉复查规范](VISUAL_REVIEW_GUIDELINES.md#3-截图与测量步骤) 保存完整截图、局部图和叠线图，标出内容起线、中心线、文字基线及间距。按钮逐状态标出背景边界、内边距、外围留白和焦点外沿；图标复查同时检查实际着色轮廓和两态中间帧。脚本测量后继续以 100% 实际尺寸人工检查层级、重心与疏密。

建议结果记录包含：日期、涉及页面、记录／分组数量、Windows 显示缩放、窗口尺寸、页面缩放、设备像素比、测量值、人工观察、发现并修正的界面问题，以及仍待检查的具体场景。报告分列代码检查、几何测量和实际画面复查。
