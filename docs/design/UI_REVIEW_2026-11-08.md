## 图标与选择浮框

- 默认图标保留线型。实际 CSS 动画的实心层从底部进入，中间帧约为 50% 填充，悬停或键盘焦点时完整填充，移出或失焦后恢复线型。
- 禁用状态保持线型；开启减少动态效果后，状态立即切换。
- 按钮文字切换为“正在查找…”并恢复后，文字完整保留，装饰图标保持一份。
- 时间和倍速浮框默认聚焦当前项，支持键盘选择。再次点击触发按钮、按 Escape 或点击外部均可收起；取消操作保持原值。
- 8 个建议只直接展示两项；更多建议可搜索，已有组与新组图标不同。关闭建议浮框保留当前记录和浏览位置；新建分组仍需确认。
- 日期或分组浮框返回较晚时，测试确认其不会覆盖已经切换的页面，也不会在新页面写入分组。
