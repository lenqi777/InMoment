# InMoment 系统极限与视觉验收清单

更新日期：2026-11-09。用于本地完整版本验收，与 UI、动效和视觉规范配套。

验收分为功能、数据与恢复、布局与可访问性、实际视觉四条线。每项记录通过、发现问题、修复后通过或未执行，并链接测试与截图。源码尺寸一致不代表视觉通过；截图要由独立审阅者查看。

## 公开依据

- [Microsoft Windows 开发最佳实践](https://learn.microsoft.com/en-us/windows/apps/get-started/best-practices)：多窗口尺寸、DPI、键盘可达、清晰状态与缩放验收。
- [Windows 可访问性测试](https://learn.microsoft.com/en-us/windows/apps/design/accessibility/accessibility-testing)：控件语义、显示设置和辅助技术检查。
- [Apple 布局指南](https://developer.apple.com/design/human-interface-guidelines/layout)：信息层级、关联分组、对齐及长内容适配；沿用 InMoment 的 Windows 配色与交互。
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：键盘操作、焦点可见、不被遮挡、文本与图形对比度、重排和目标大小。
- 根据功能改动及影响范围挑选自测、功能验收和集成回归场景，分别记录结果。[字节跳动 SmartEye 精准测试实践](https://developer.volcengine.com/articles/7599493947916582938)

## 极限数据

- 标题：缺失、空白、1 字、最大允许长度、超过限制；正文：空、2000 字、100000 字及服务上限前后。区分允许的数据与应被拒绝的输入。
- 混合中文、英文、数字、emoji、连续无空格长串、长网址、多个空行、长代码、多个宽表格；不得执行 HTML 或将文字当程序。
- 多条记录、多个分组、长名称、分页；额外压力库使用约 240 条记录与 80 个分组，基准库保留既有 49 条／8 组。
- 多段音频、静音、缺失／无效媒体与延迟读取；多图、满额引用、长错误和长输入组合，工具条必须可操作。
- 空结果、缺少标题／正文／图片／音频时没有重复空区块，提供明确的当前可执行动作。

## 交互和数据可靠性

- 每条主要流程检查正常完成、取消、重复点击、快速反向、切走页面、迟到结果与失败恢复。
- 保存先落盘后清空；失败保留原输入／附件。关闭、删除和清理先失效回调，不触碰已保存或正在提交的录音。
- 正式聊天重启可恢复；临时浮窗三种关闭决策、空白直接关闭、跨窗口转移均正确。
- 只处理点击时的筛选范围和选中集；取消、切换或删除后旧结果不写入新对象。
- 记录每个场景的耗时、渲染错误、未处理异常、附件哈希及残留任务；检查是否出现无限等待、整页卡死或不受限增长。

## 布局和实际视觉

- 主窗口复用六组既有尺寸／缩放矩阵，并补大屏和关键页 200% 缩放；800px 宽为压力条件，产品正常最小窗口仍为 1000×700。
- 浮窗检查初始尺寸、有效窄宽、100%／125%／150%／200% 缩放和长内容增高；视口不足时滚动，按钮不被挤掉。
- 对每个主要页面保存原始截图、局部图和叠线测量，再独立查看层级、疏密、光学中心与实际轮廓。
- 图标逐组比较可见大小、线重、层级、与文字比例、图文间距、按钮间距、同心圆角、默认与悬停底块。不能仅以 SVG 框或 CSS 数字相同认定通过。
- 每类按钮检查默认、悬停、按下、焦点、选中、禁用、处理中和失败；状态变化不改变几何，颜色同时有图形／名称语义。
- 检查键盘可达、焦点返回、焦点不被裁切、IME、减少动态效果；辅助技术或其他实体设备未实际运行的项目单独记录。

## 执行与交付

全部使用隔离资料、合成音频／图片、模拟响应与应用自有窗口截图。真实模型、API、麦克风、桌面截图和用户库不在自动验收中调用。

执行顺序为：确认范围与通过条件 → 本地单元／集成 → 正常功能与恢复 → 大量数据及尺寸极限 → 独立逐图复查 → 修复定向复测 → 程序包检查。图形自动化顺序运行，避免多个驱动争用前台窗口；只读审图与源码检查可以并行。

| 可复用入口 | 作用 |
| --- | --- |
| `pnpm test`、`pnpm check` | 模拟服务、持久化、清理／取消／迟到结果、语法和凭据模式 |
| `node scripts/ui-audit.cjs` | 主窗口尺寸／缩放、动效、图标和公共控件 |
| `node scripts/ux-smoke.cjs` | 真实渲染器／本地通信的正常功能、取消与重启 |
| `node scripts/ui-main-extreme.cjs` | 240 条记录、80 个分组、长／空内容与 200% 缩放 |
| `node scripts/ui-audit.cjs --button-states-final` | 控件默认、悬停、按下、焦点和禁用边界 |
| `node scripts/chat-extreme-audit.cjs` | 主聊天／浮窗尺寸矩阵、长候选、满额附件、长消息与关闭决策 |

图形脚本需要已安装的 Playwright，可通过 `INMOMENT_PLAYWRIGHT` 指定位置；输出目录环境变量及隔离资料保护见脚本开头。原生输入证明须显式设置测试开关，只向测试自有前台窗口发送标记输入。

数据丢失、安全或关键功能不可用的问题先修复再交付；布局与视觉问题给出具体截图、位置、原因和复测结果。完整报告包含覆盖清单、缺陷及修复、未执行项目、截图索引、原始测量和最终程序源码一致性校验。
