# InMoment 动效规范

更新日期：2026-11-11。适用于应用内导航、录音内容、筛选、浮框、弹窗、编辑和图谱操作，与 [UI 规范](UI_GUIDELINES.md)、[检查清单](UI_CHECKLIST.md) 一起使用。

动效说明一次操作改变了什么，以及内容从哪里来、回到哪里。每个改变界面状态的交互都要选择对应的过渡；连续操控和输入即时响应。

## 1. 类型与时长

下表对应 `src/shared/ui-motion.js`、`ui-motion.css` 和 `ui-controls.css` 的当前实现。进入和退出是一组行为，新增界面时同时接入。

| 交互 | 时长 | 表现与适用范围 |
| --- | --- | --- |
| 功能图标悬停／键盘焦点／持续选中 | 180ms，反向同长 | 官方 Regular 与 Filled 互补擦换，面型自下而上出现，线型同步退出 |
| 聊天发送按钮内容状态 | 180ms，反向同长 | 无可发送内容显示线型，有内容持续显示面型。输入或清空最后一项内容触发互补擦换 |
| 录音品牌／播放／暂停形变 | 320ms | 两条实际着色轮廓连续插值；固定圆形底与锚点，从当前画面接续反向操作 |
| 胶囊进入浮动聊天 | 320ms | 同一白色表面由原胶囊矩形向右上展开，实际宽高／位置与内容裁切同步；字号保持不变 |
| 从网格打开记录 | 280ms | 以被点击卡片的可见矩形为起点，过渡到详情区域 |
| 从详情返回网格 | 240ms | 详情回到原卡片；原卡片已不在当前列表时使用网格容器作为目标 |
| 在记录列表切换记录 | 180ms | 详情区域内切换，保留列表位置与导航结构 |
| 页面切换 | 180ms | 旧页淡出，新页淡入并轻移；旧页淡出为 120ms |
| 语音文本／思考摘要切换 | 几何组 160ms | 旧文本 90ms 淡出；新文本延迟 30ms 后用 140ms 淡入，播放器保持原位 |
| 详情数据就绪／筛选结果／状态提示 | 180ms | 从下方 6px 轻移并淡入；一般内容显现也复用此反馈 |
| 窄窗口分组侧栏 | 进入 220ms，退出 180ms | 从左侧 20px 范围进入或退出；窗口宽度不大于 900px 时使用 |
| 笔记列显示 | 即时 | 启动时显示完整列宽，切组在原列更新，窄窗口从正文返回时直接显示列表 |
| 就近小浮框 | 进入 180ms，退出 120ms | 从锚点方向轻移、缩放并淡入／淡出；上下展开使用对应方向 |
| 应用弹窗 | 进入 220ms，退出 120ms | 小幅纵向位移、缩放与淡入／淡出，背景遮罩同步处理 |
| `details` 展开／收起 | 200ms／160ms | 从当前可见高度过渡到内容高度或摘要高度 |
| 行内编辑／自定日期展开 | 200ms／160ms | 录音原文编辑、标题编辑、创建组表单、自定日期等按实际高度展开和收起 |
| 灵感云离散缩放／聚焦／适应窗口 | 200ms | 从当前可见 `viewBox` 接续到目标，使用渐缓的三次曲线 |
| 图片缩放按钮／适应按钮 | 180ms | 从当前可见图片尺寸过渡到目标尺寸 |
| 按钮底色反馈 | 120ms | 默认透明，聊天发送与停止回复默认浅绿。悬停、按下与实际选中均叠加 4% 按钮基色。基色按 [按钮语义](UI_GUIDELINES.md#2-颜色与表面) 选择，图标与文字保持语义色 |
| 按钮按下／释放 | 90ms | 按下轻缩至 97%，释放恢复尺寸。单次动作按指针位置恢复底色，实际选中项在指针移开后仍保留 4% 底色 |
| 开关反馈 | 120ms | 开关的颜色或位置随状态变化 |
| 分组列收起／展开 | 180ms | 分组列与左侧操作栏等宽后保留展开入口，展开恢复共享列宽。笔记列和正文随可用空间移动 |
| 拖动、滚轮缩放、音频进度定位、输入 | 即时 | 直接跟随手势、光标和输入，连续操作过程中不排队等待补间 |

通用出现、退出和高度过渡使用 `cubic-bezier(.2,.75,.25,1)`；图标擦换使用 `cubic-bezier(.2,.65,.3,1)`。相关值有变更时，同步更新本表和检查项。

### 记录打开与返回

记录导航使用浏览器原生 View Transition，将来源卡片和目标详情匹配为同一组，保留两处矩形之间的空间关系。根页面不做整屏淡化。返回时恢复分组主页和先前滚动位置。

记录资料异步加载：打开时先使用当前列表中已有的标题与最多 360 字短文本呈现只读预览，并标明正在读取完整记录；没有缓存时显示读取状态。完整资料到达后再呈现可操作内容。导航版本发生变化后，旧读取结果不覆盖新记录。当前浏览器不支持原生过渡或来源不可见时，直接完成状态切换，再使用轻量内容出现；开启减少动态效果时直接显示最终状态。

### 图标两态

使用官方 20px 光学版本的独立 Regular／Filled SVG，分别作为 `.ui-icon-outline` 和 `.ui-icon-solid` 的图形。悬停、键盘焦点或持续选中触发自下而上互补擦换。面型出现的区域同步退出线型，终态显示一份完整面型。

持续选中的按钮在移开鼠标或焦点后仍显示面型。悬停、键盘焦点和持续选中均结束后反向恢复。快速改变状态时，从当前显示进度接续。单四角星、加入已有组、新建组、播放和删除等均使用同一过渡。非交互品牌、装饰和原生窗口按钮各用静态或系统反馈，录音品牌控制沿用专用路径形变。

[聊天发送按钮](UI_GUIDELINES.md#聊天发送按钮)以可发送内容的有无为触发条件。加入内容后完成擦换并保持面型，清空最后一项内容后反向擦换至线型禁用状态。快速输入后清空从当前进度反向，开启减少动态效果时即时到达目标图标。

### 浮框与弹窗

浮框以触发控件为锚点，位置优先在下方，空间不足时移到上方，并保留窗口边距。上方浮框从下缘方向出现，下方浮框从上缘方向出现。

关闭开始时立即停止交互和监听，再完成退场并移除节点。Escape 和菜单操作关闭后按规则恢复焦点；外部点击保留新目标的焦点。再次打开时处理上一轮退场，界面上只有当前可交互的浮框。

弹窗关闭后，原生模态状态及时结束；剩余退场画面通过本地 DOM 副本显示。副本设为 `inert`、`aria-hidden`，不接收点击、焦点或媒体播放；退场完成后移除。

### 展开与连续操控

录音胶囊以 Logo 为固定锚点，保持 Logo 的屏幕坐标和尺寸，表面向右、下展开并反向收回；展开约 280ms，收回约 180ms。紧凑和展开状态复用同一份 Logo、录音条与计时，波形实际跨度约 111px，两侧可见间隔相等。手动暂停→准备→继续录音保持展开，不插入收回胶囊的过渡。参考图只用于该形状与过渡，配色沿用公共样式，卡片和原生浮窗均不使用外部阴影。长按确认阶段保留原有水平进度条和时序，进度即时跟随按住时间。减少动态效果时立即切换。音量驱动的录音条及圆形 Logo 光晕及时跟随真实音量，不用自动循环伪造声音活动；暂停、完成和丢弃立即归零。

录音左侧圆形控制复用 `src/shared/brand-morph.js`：首次长按显示品牌 i，首次松开后连续变成播放动作；同一草稿以后只做播放↔暂停双向形变。金色、米白两条路径按等弧长对应点插值，采用 320ms 三次渐入渐出，不能以淡入淡出或图片替换充当形变。快速反向从当前可见路径接续，重复状态不重启动画；新草稿立即重置为品牌形态。减少动态效果预先或中途启用时，取消待执行帧并立即到达目标轮廓。

浮窗在新草稿首次触发时建立屏幕锚点；同一草稿的暂停／继续、准备、失败与重新显示只更新内容，保持原生窗口位置。动画验收同时核对原生窗口和内部 Logo 的屏幕坐标，连续切换不能累积跟随鼠标偏移。

进入聊天先收回录音面板，再读取实际胶囊边框的屏幕矩形。聊天窗口在隐藏状态准备完整布局与胶囊首帧，准备完成后显示并隐藏来源浮层；白色表面的真实边界、圆角和内容裁切按 320ms 三次渐缓曲线展开。原生窗口包含四周 12px 透明投影留白，坐标换算以白色内容边界为准；起始胶囊保持 24px 圆角且无投影，终态到达 36px 圆角并显现柔和投影。初始胶囊外区域透明，笔画与计时短暂保留后退出，聊天内容随后显现，文字不做整体缩放。空间足够时保留胶囊左缘／底缘，临近工作区边缘时从原位置向可用范围展开。

动画期间暂缓原生窗口的自动增高，结束后重新测量输入布局。关闭、转到主窗口或退出使旧交接失效，旧回调不能再次显示窗口；视觉准备失败保留来源与临时录音供重试。减少动态效果预先或中途启用时立即清理胶囊副本并呈现最终聊天。仅用户关闭、删除等既有动作执行对应资料清理。

隐藏窗口只提交初始布局，不等待隐藏状态下可能停止的动画帧。聊天可见后确认首帧，再隐藏来源并开始展开；首帧等待有短时间上限，关闭等中断后仍检查当前交接标识。

内容展开使用实际高度，结束后恢复自然布局，使长语音文本、不同表单和缩放后的内容都能完整显示。收起时保留短暂的高度占位并逐步收拢，周围内容跟随变化。

灵感云的缩放按钮、聚焦和适应窗口使用短过渡。用户开始拖动或滚轮操作时，接管当前可见位置并即时跟手。图片的缩放按钮使用短过渡，滚轮围绕光标即时缩放，拖动即时平移；音频进度与播放时间即时同步。

## 2. 中断与最终状态

笔记选区菜单与改写浮框复用共享浮框的进入与退出，浮层位置随滚动和缩放即时更新。菜单项使用公共按钮三态，四角星动作叠操作绿。提示词、处理状态与结果在同一个锚点替换，原选区高亮及正文排版保持稳定。Esc 关闭并恢复正文焦点和选区。切换笔记、编辑原文或关闭浮层时使旧响应失效，减少动态效果时即时切换。

笔记格式工具在正文选区稳定 1 秒后显示。拖选期间不开始计时，选区变化重新计时，正文快捷键 Ctrl+Shift+F 可直接打开。沿用共享浮层的进入与退出；滚动或缩放时即时跟随可见选区，正文保持原位，选区滚出可见区域后收起自动浮层。Escape 和切换笔记清除待显示状态；减少动态效果时保留 1 秒触发条件，显隐即时。

聊天加号菜单的「引用笔记」子面板复用共享浮层进出动效。鼠标移入条目时展开，从菜单跨到子面板时保持打开。键盘进入或点击清空叉号后，焦点落到搜索框。Esc 先返回加号菜单。

正文图片和视频的边角缩放随指针即时重排，松手提交尺寸，取消恢复拖动前的大小。拖放位置和文字环绕方式一起提交，连续拖动期间只更新落点提示。

笔记大图预览复用公共弹窗进出。缩放、平移、文字拖选与标注即时响应，文字框跟随图片坐标。识别在后台进行，切换图片或关闭预览后，旧结果退出当前界面。替换图片后以新版本的像素坐标识别。

聊天入口复用页面切换过渡。会话操作面板、笔记引用选择器和选择工具栏的显现与退出复用 `show()`。输入、语音候选和流式文字即时响应，不为每个 token 排队动画。快速切换会话时，只有最新读取结果可以更新当前画面，输入框焦点与尚未提交的文字保留。

聊天加号菜单复用公共浮框的 180／120ms 进入与退出。聊天图片预览复用弹窗进入与退出，关闭后释放原图引用并恢复缩略图焦点；图片缩放与拖动即时响应。采用转写是即时编辑，不排队等待动画，也不因焦点过渡回退为提示。

聊天录音各控件保持原位，发送以降低强调的墨绿显示禁用状态。单个加号以 180ms 旋转 45° 成为取消叉号，取消或完成后反向恢复。品牌播放／暂停轮廓沿用 320ms 连续形变，底色按绿色三态反馈。波形独立绘制，占操作与录音之间空白的 80%，真实 PCM 音量即时更新，无自动循环。停止、取消、关闭或失效时归零，识别文字直接插入正文。恢复同一聊天不重播进入动画，减少动态效果时立即切换。

剪刀每次移入只播放一轮 360ms 开合，持续停留不循环，移出取消并复位；减少动态效果保持静态。悬停或键盘聚焦 1 秒显示紧凑胶囊；离开按钮与胶囊双方后延迟 1 秒关闭，进入任一区域或保留选项键盘焦点时取消关闭，Escape 立即关闭。截图先隐藏指定聊天并等待画面退出，再获取静帧；框选、绘制、撤销与重做即时跟手。浮动提示沿用 180ms 进入／120ms 退出，预览遮罩保持透明。

截图录音随拖动即时更新选区。首次有效松手后，普通录音胶囊在编辑器上方出现，编辑器与标注保留。拖动录音浮窗即时跟随，暂停和继续在原位置切换。确认或取消截图后原浮窗自动展开，录音计时连续，暂停状态仍显示累计时长。

回放波形已播放着色与实际音频进度即时同步，点击、拖动和键盘定位不增加位移动画。波形异步就绪只替换轨道表现，控件位置、当前时间与播放状态保持不变。

输入、候选采用、粘贴和删除引起的输入框高度即时更新，浮窗高度同步增大并限制在当前显示器工作区。到达上限后只滚动输入内容；光标、文字和工具栏的位置关系保持稳定，不为每次按键叠加高度动画。长文本、窗口缩放与输入法组合时重复测量实际可用空间。

聊天阅读位置独立于输入保存：逐字输入、输入法组词和相同消息回写保持可见消息锚点，只在原本贴底时跟随新回复。点击“回到底部”或侧边提问短线使用平滑滚动；用户滚轮或拖动立即接管，减少动态效果时直接定位。悬停时短线在 120ms 内沿固定左缘伸缩，减少动态效果时直接应用目标长度。导航预览只显示提问文字，不改变正文和输入区尺寸；跳转不自动聚焦输入框。

聊天短线超出可见区域时，鼠标停在顶部或底部 22 CSS px 内以每秒约 120 CSS px 滑动导航，边缘范围最多为可见高度的四分之一。离开边缘、到达列表尽头或按下鼠标即停止。正文滚动同步阅读标记，将对应短线带入可见区域。主动浏览短线期间保持导航的滚动位置，结束浏览后同步待显示的阅读标记。

1. 同一元素的新动画取消上一段动画，从当前可见状态或当前尺寸接续。
2. 新导航跳过上一段原生 View Transition。只有当前导航版本可以提交读取结果和清理自己拥有的过渡名称。
3. 展开、收起和再次展开使用当前操作标记，旧回调不覆盖新高度、可见性或最终开合状态。
4. 关闭过程中停止接收操作，重复关闭只执行一次；再次打开时清理旧退场画面。
5. 动画完成、取消或页面切走后，临时名称、尺寸、占位、遮罩和副本均需清理。最终焦点、内容和点击范围与当前状态一致。

状态更新和动画分工明确：保存、删除、草稿清理、录音暂停与权限判断沿用业务时序；视觉退场不延迟安全清理，也不让旧回调重新激活已关闭内容。截图录音快捷键在按下时即时显示，抬起后保存；取消立即恢复当前快捷键的显示。

## 3. 减少动态效果

使用系统 `prefers-reduced-motion: reduce`，主窗口和录音浮窗共同遵守：

- 页面和记录直接显示目标状态；图标立即切换两态。
- 按钮底色即时切换，按下保持原尺寸。
- 侧栏、浮框、弹窗和展开内容直接显示或隐藏，不做位移、缩放或高度补间。
- 灵感云和图片直接应用目标视图；拖动、滚轮、输入及音频定位仍保持即时响应。
- 用户在动画中途开启减少动态效果时，取消当前补间，结束正在运行的原生过渡并清理临时画面；图谱到达本次目标视图。

## 4. 开发入口

| 用途 | 入口 |
| --- | --- |
| 页面、记录和文本内容切换 | `InMomentMotion.transition()` |
| 浮层显现与退出 | `enter()`、`exit()` |
| 共享内容可见性和行内高度 | `show()` |
| 窄屏侧栏 | `sidebar()` |
| 退场副本 | `snapshot()`、`leaveSnapshot()` |
| 内容折叠 | `details()` |
| 图谱视图 | `viewBox()` |
| 图片尺寸 | `imageSize()` |

共享脚本自动处理应用弹窗与 `details` 摘要点击。浮框组件在 `src/renderer/popovers.js` 中接入进入、退出、定位和焦点；页面与记录导航在 `app.js`，图谱连续与离散操控在 `cloud.js`。

新增改变界面的交互时，先确定所属类型，接入共享入口，再补充对应检查。选择正确的来源和目标，保持减少动态效果、快速反向操作和页面切换时的最终状态。

## 5. 验收

主窗口新聊天的欢迎内容与输入区在可用区域约 38.2% 处成组呈现；首条消息发送后输入区回到底部，沿用共享内容过渡。语音只更新原位波形和控制状态，不移动其他输入元素。历史名称编辑只替换对应行，流式回复不重建正在编辑的行；卡片／列表切换复用记录节点，保留选择与焦点。

多选存为笔记的 AI 总结浮框与截图选项共用悬停／聚焦 1 秒出现、离开双方 1 秒退出的规则，进入和退出沿用共享浮框过渡。点击总结按钮才触发模型调用。切换会话、选择与录音状态时取消计时并关闭旧浮框。减少动态效果时保留等待与操作语义。

对每类交互检查起点、中间帧、终点和反向操作。快速重复打开／关闭、连续切换记录、动画中途切走页面及中途开启减少动态效果，均应到达最后一次操作的正确状态。

布局验收沿用 [UI_CHECKLIST.md](UI_CHECKLIST.md) 的窗口与缩放组合。自动检查使用隔离记录、合成音频、模拟 AI 结果和应用自有窗口画面，不调用真实模型或服务。
