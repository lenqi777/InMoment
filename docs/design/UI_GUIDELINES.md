# InMoment UI 与交互规范

更新日期：2026-11-11。适用于 Windows 主窗口、录音浮窗、设置、灵感云和应用内浮框。

InMoment 的界面围绕随手录下和集中回看展开。白色承载内容，中性灰区分层级，按钮按动作语义显示状态。笔记正文直接编辑，保留的录音和采集资料通过「背景信息」查看。

## 参考范围与已有行为

- 参考图片只应用用户明确指定的形状、布局或交互维度。以灵动岛为形状参考时，沿用 InMoment 的白、灰、绿配色与公共组件，不引入黑色主题。
- 调整外观保留现有加载进度、状态提示、快捷操作及数据时序。更换某个反馈形式属于行为变更，须有用户明确要求；原有水平长按进度不能用 Logo 光环代替。
- 普通配色下，编辑框通过光标与文字选区呈现焦点，保持原边框和底色。键盘访问按钮等控件时用底部短线提示焦点，文字链接及折叠入口用下划线。系统高对比度模式使用系统焦点色。

## 录音胶囊

- 长按确认前保留原有可见水平进度条，准确反映既定触发时间；提前松开可取消，不启动录音。确认后进入白色胶囊，两端为完整半圆；以左侧 Logo 为固定坐标锚点向右、下展开，收起反向进行。Logo 的大小与屏幕坐标在起始、中间和结束帧一致。
- 紧凑胶囊只显示三项：左侧专门设计的圆形品牌 Logo、中间录音条、右侧等宽录音时长。圆形版本使用独立矢量路径，按圆形空间重新设计字形和留白；不裁剪或放大方形 Logo。外框左上圆角半径 24px，Logo 半径 14px，可见圆形距外框左／上边各 10px，二者共用圆心。
- 麦克风开始后，绿色录音条与 Logo 周围的轻量光晕由本机音量驱动，静音保持低幅，不播放假波形循环。光晕表达音量，不替代长按加载进度。左侧圆形是唯一的暂停／继续按钮，提示与可访问名称同步当前动作。
- 新草稿首次长按时显示品牌 i，首次松开暂停后变为“点击继续”的播放形状；此草稿后续只在播放与暂停之间变形，不恢复品牌 i。暂停采用候选 4 的圆润双笔，播放采用候选 3 的圆润切口；圆形底、尺寸和锚点始终不变。录音中显示可点击暂停，暂停时显示可点击继续。
- 紧凑胶囊的录音条实际着色跨度约 111px，为原 51px 的约两倍；展开面板保留同一录音条与时长。移除大圆、劝说式状态段、右上状态字样和单独的右侧播放／暂停按钮。
- 问 AI、删除和「存为笔记」组成紧凑操作组，同一基线排列。相邻底块间隔 8 CSS px，按钮左右内边距各 8 CSS px，图标与标签间隔 4 CSS px。三项共用 12px 圆角，按各自动作的语义色叠色。可用宽度不足时按按钮换行。卡片和胶囊使用细边界。
- 圆形 Logo 按圆角同心关系定位；分组与底部文字区使用独立、更靠内的公共起线，不强行与圆形左缘共线。先检查可见文字、图形到左边和底边的留白，再判断整组视觉重心；不能用路径坐标相等代替实际画面的舒适度。上下三行收紧后仍保留独立点击范围。
- 当前录音面板标准宽 260px、收起分组时高约 124px。文字区可见左留白约 20px，底部文字到外框约 23px。Logo 透明点击框 32px，内部可见圆形为 28px 且锚点固定。分组展开入口与动作点击框至少高 32px。长分组与错误按实际内容增高，底部动作保持完整。
- Logo、录音条实际着色范围与计时之间的两段水平空白相等，按可见图形测量而非仅按容器；去掉计时前的多余伸展空白。录音面板内同一分组的行距、内边距小于该分组与上下区域的间距。
- 初次长按及截图录音开始后使用同一紧凑胶囊。手动继续时保持展开，分组控件保留展开状态。截图录音使用相同的暂停、继续、留存和保存操作。
- 浮窗只在首次触发新草稿时按触发位置定位。截图录音的紧凑胶囊和所有录音的展开面板可从波形、计时等顶部空白处拖动。同一草稿的后续状态复用当前位置。Logo、按钮、文本框和分组选择仍直接操作。
- 首次右键松开暂停，继续后免按录音，点击左侧图标暂停。所有录音段仍属于同一草稿，完成和丢弃的数据时序保持不变。
- 新录音默认勾选「保留文字」，「保留录音」可同时勾选。最后一个已选项保持选中，勾上另一项后可以切换。暂停后本机转写新增语音，点击「笔记正文」即可编辑。转写失败时可手动填写、重试或只保留录音。保存确认后，正文进入笔记，保留的录音和来源资料进入背景信息。
- 胶囊与展开面板统一使用公共白底、正文色、次级灰、绿色操作和危险红色，不另设主题。圆形品牌本体保留既有深绿、米白和金色识别元素。

## 主窗口外壳

- 笔记、聊天、偏好设置和恢复录音共用顶部标题栏和左侧操作栏。标题栏高度和左栏宽度同为 46 CSS px，随原生窗口控件所需空间调整。Windows 窗口按钮高度按其宽度校准。两栏连续使用微绿灰，交界无分割线，内侧内容区左上角统一用 16px 圆角。切换页面时，Logo、品牌文字、操作图标、窗口控件与内容起线保持原位。
- 左侧操作栏使用公共中性灰三态。44 × 44px 点击框内的底色为 36 × 36px，四边各内缩 4px，可见圆角为 12px。图标在点击框中心，当前页保留触发态底色，键盘焦点按公共按钮规则呈现。

## 笔记

- 笔记是启动页和已保存资料的入口。启动时笔记列直接显示「全部笔记」。桌面展开的分组列、笔记列和主窗口的聊天历史栏共用一个响应式列宽。分组和笔记等宽、同高，使用同一种浅中性灰。窄窗口从标题栏打开分组抽屉，在正文保留返回笔记列表按钮。
- 点击分组时，在原列更新组内笔记。点击笔记打开正文，窄窗口从正文返回时直接显示笔记列表。空白页采用「纸页起笔」，放大的无底色品牌 i 放在「写下第一句」左侧，二者同排。「新建笔记」下方显示按编辑时间倒序排列的最近三条笔记，点击直接打开正文。笔记列表顶部先显示搜索，下方同一行左侧多选、右侧新建图标；「未分类」额外提供 AI 分类。每条笔记第二行日期靠左、时间靠右，标题只占一行。新笔记在产生标题、正文或附件时落盘。
- 分组和笔记列顶部各放一个 18 CSS px 标签，字重 400，使用与「多选」相同的次级文字灰。标签共用 48px 标题行、32px 行高、16px 内边距与文字起线。两列下方搜索框等宽等高，共用 36px 高度、相同内边距和图标位置。分组标题行右侧的开合按钮使用三条圆端横线和箭头。分组展开时箭头向左，点击收起至左侧操作栏宽度。收起后图标水平镜像，箭头向右，点击展开并恢复原搜索、选择和滚动位置。按钮沿用公共图标两态和灰色底色反馈。
- 搜索框下方分组工具左侧为多选、右侧为新建。分组树独立滚动，「未分类」固定在底部并与左栏设置按钮中心对齐。搜索保留命中项的父级路径。分组和笔记保留各自的总选复选框和多选入口，右键菜单提供分组和笔记操作。删除分组与删除内容分别呈现，危险操作先确认。
- 分组和笔记可以导出 PDF 或 Markdown。多个笔记可合成一个文件，也可各自输出一个文件。附件随导出结果放在同目录的附件文件夹。
- 最左栏仅在有可恢复的本机录音草稿时显示「恢复录音」及条数。当前正在记录的草稿用录音面板及主窗口状态条控制。
- 编辑区上方的「背景信息」为小图标按钮。存在来源、截图或录音时才显示。弹窗按内容组织信息，可播放原录音和预览原图，关闭后暂停音频并恢复焦点。
- 已保存的笔记保留非空正文时，可从背景信息确认移除录音，保留截图和来源。没有背景资料的笔记不占用入口空间。
- 编辑笔记标题时按 Enter，将光标移到正文起点。输入法组词期间用 Enter 确认候选，焦点留在标题。正文里的 Enter 沿用段落编辑行为。
- 松开鼠标或结束键盘选择后，选区稳定 1 秒再显示格式浮层。浮层水平对准可见选区首行的中心，底边距首行上边 8px，左右越界时贴齐可见编辑区边界。上方放不下时紧贴选区末行下方，两侧均放不下时按可用空间约束。正文顶部不设独立格式按钮。在正文按 Ctrl+Shift+F 可直接打开。浮层依次显示当前段落样式、字号数字、B、I、U、当前文字颜色圆点和 Ω。颜色按钮与调色菜单共用 14px 圆形色块，默认显示正文黑色，换色时同步更新。图标与色块在等高点击框内居中，按钮保留中文悬停提示和可访问名称。段落菜单提供正文、三级标题、「• 项目符号列表」、「1. 编号列表」和引用。浮层保留原选区和正文位置，应用后焦点回到正文，Escape 关闭。
- 添加或粘贴的图片和视频插在正文光标处。拖动媒体把手可换位置，放到段落左侧或右侧时让文字环绕，放到正文中间时恢复独占一行。移动菜单可切换排版方式和阅读顺序。拖动媒体边角按比例缩放，正文即时重排，位置、环绕和大小随笔记保存。旧笔记中已有的图片和视频初次打开时显示在正文末尾。PDF、Word 等文件显示在附件区。
- 点击图片可单独选中，按 Enter 或点击图片下方可继续正文。点击独占一行图片旁的空白处可切换为「与文字同行」并放置光标，媒体移动菜单也提供此排版。同行图片的可见下沿对齐文字基线，点击空白处的光标位于同一行。左右环绕时在可用的文字区域直接定位光标。排版随笔记保存，键盘移动和换行沿用正文编辑行为，拖动与缩放仍由媒体把手操作。
- 双击正文图片或用「查看大图」打开原图预览，单击保留正文选图。预览在本机识别图中文字，直接拖选文字并用 Ctrl+C 复制，拖动空白区平移。「提取图片文字」可查看整图或框选区域的结果，复制全部或将识别文字插入当前图片下方。保留识别的段落和换行，插入算一步笔记编辑。识别进度、无结果和失败都在预览内反馈。
- 「编辑图片」展开截图标注工具和裁剪、旋转、荧光笔。编辑中撤销或重做单次操作，输出合成图保持原始像素比例。「替换笔记中的图片」提交当前图片并保留正文位置、宽度和环绕，可用笔记撤销恢复。「复制编辑后的图片」只写入图片剪贴板。离开有改动的编辑器前可继续编辑或放弃。背景来源截图可提取文字或复制编辑后的图片。
- 单独复制正文图片时，将图片写入 Windows 剪贴板的图片格式。跨越文字和图片选择后复制，富剪贴板内容保留选中范围和图文顺序，粘贴到笔记光标或选区后仍可编辑。在只接收纯文本的位置使用文字内容。普通纯文本粘贴沿用原行为。
- 每篇笔记有独立的撤销与重做记录。一次图文粘贴作为一步编辑。Ctrl+Z 恢复粘贴前的文字和选区并移除本次插入的图片，Ctrl+Y 或 Ctrl+Shift+Z 重做这次粘贴。
- 图片与文字之间的空行可以单独删除。空列表项的退格先退出列表。删除选区内的图片用正文的删除操作，图片也可用自己的移除按钮。
- 笔记顶部的「总结」按钮由墨绿四角星和文字组成，图标在左。点击后在当前笔记的附件区加入一份可打开、可编辑的总结笔记。原笔记的标题和正文保留。
- 每个附件右上角放一个小叉号，沿用危险色、悬停反馈和键盘焦点样式。点击直接移除该附件，其他附件和笔记正文保留。
- 选中正文后，右键或键盘唤起圆角菜单。「总结」「改写」用墨绿文字和四角星，底块按绿色三态反馈。键盘焦点显示底部短线。菜单及后续浮层获得焦点后，原文字选区仍以淡绿高亮显示。
- 选段反馈用白色圆角浮层，默认在可见选区首行正上方居中，间隔 8px，越界时按可见编辑区限位。上方空间不足时放到选区末行下方。自动位置随滚动与缩放更新，正文及附件的排版保持原位。
- 提交请求、等待、返回改写稿或返回总结时，保留原选区，状态通过文字反馈。取消按钮与结果框由用户操作获得焦点。改写预览使用深色文字，仅在实际替换内容后加浅绿高亮，用户手动选中的文字用浅蓝底，保持相同的深色前景。
- 改写输入胶囊只放两项，左边是单行提示词输入，右边是发送图标。输入框透明、无描边或阴影，聚焦以光标和文字选区表示，系统高对比度模式保留可辨认的焦点。处理反馈和可复制的总结沿用同一个浮层。改写稿在浮层内预览与前后原文拼接后的内容，高亮实际替换部分，长内容在预览区内滚动。勾号接受并替换原选区，叉号关闭改写稿，接受后可用正文编辑的撤销快捷键恢复原文。
- 改写结果可从浮层标题拖动，限制在可见编辑区。移动时保留原选区，预览正文仍可选中复制。对现有列表明确要求补充条目时，预览新增项，确认后追加到该列表末尾。已有条目及原有换行保留，只有重复内容时显示重试反馈。

## 聊天

- 非截图录音的上滑入口使用胶囊上方居中的绿色小字「上滑问 AI」。新草稿先显示约 2.2 秒，之后悬停或键盘聚焦胶囊时显示。提示位于胶囊外的独立留白，进入聊天立即隐藏。
- 从录音进入聊天时，先将录音面板收回胶囊，再从同一块白色表面向右上展开；使用实际胶囊屏幕坐标，保留公共配色与细边界。起始胶囊保持 24px 圆角，终态聊天为 36px 圆角及柔和扩散投影；原生窗口为投影预留四周 12px 透明空间，四边与底部投影完整显示。录音胶囊及录音面板仍沿用无投影规则。空间足够时白色表面的左缘与底缘固定，临近屏幕边缘时限制在工作区内。
- 浮窗打开默认不聚焦输入框，转写完成不主动抢焦点。用户点击或按 Tab 后显示输入光标，外层保持原中性边框。按钮与菜单按公共规则显示键盘焦点短线。
- 最左操作栏提供聊天入口。历史列从上到下为标题、透明整行“新聊天”、搜索和聊天记录。每条聊天的标题和更多按钮共用一块 12px 圆角行底色。悬停任一入口时整行显示浅灰，当前聊天持续保留相同的浅灰，标题沿用正常字重。历史列底部不放重复的临时聊天清理说明。
- 新聊天未发送时欢迎图标位于标题左侧、同行居中；主窗口的欢迎标题、说明与输入框成组位于标题栏下可用区域约 38.2% 的高度，窄小窗口和长内容按可用空间收敛，保留工具栏。浮窗保留既有欢迎定位。不提前加入历史；首次发送成功进入消息流程后才展示历史条目。软件内语音和截图复用当前聊天页及输入，外部捕捉才使用浮动聊天入口。仅有图片时也允许发送，默认请求解读图片。
- 每条历史记录的打开按钮与更多按钮分别命中。更多菜单提供重命名、存为笔记、整理为笔记和删除，动作应用于菜单所属会话。首次回复时，AI 根据用户首条消息生成聊天标题，收到有效标题前显示本地标题。名称可原位编辑，勾号保存、叉号取消。手动命名优先，输入与录音状态保留，名称不可为空白。删除先确认，清理所属临时内容并使迟到结果失效，两个聊天界面同步移除条目。
- 普通设置只需选择 AI 服务、填写 API Key，默认自动选择模型。输入区的模型菜单可为聊天指定回答模型与推理强度，清楚区分自动与手动。Gemini 设置默认开启「优先使用免费模型」。
- 加号菜单可一次添加 PDF、UTF-8 文本、MP4 和图片。文件卡与图片同组，文件名在有限宽度截断并提供完整名称，移除动作保持同一点击区域。校验失败保留原输入和原附件。只附加文件也可发送。

- “不隐藏当前页面”使用 16px 圆形复选框，保持 checkbox 的可选／取消语义；绿色选中与白色勾号明确区分状态，键盘焦点可见。圆形外观仅用于此截图选项，不改变消息多选的既有形状。

- 图片预览使用透明模态遮罩，无黑色蒙层与背景模糊；预览面板保留轻量投影。关闭按钮的位置与外框相邻圆角按下述同心规则定位，按钮底块使用公共 12px 圆角。图片附件与文字之间的可见间距约 8px，为原 16px 的一半。
- 笔记正文、背景与记录截图、主窗口聊天和聊天浮窗共用同一图片预览。选字、整图及框选提取、标注和复制均在该预览中进行。笔记正文图片提供原位替换和插入文字，已发送图片及来源截图使用复制操作。主窗口原生标题栏控件在图片预览显示及退场时隐去，预览的关闭按钮保留标题栏安全间距。
- 整图与框选结果使用同一阅读面板。识别到思维导图时默认显示「大纲」，可切到「纯文字」。同框文字保持换行，分支使用嵌套列表。复制大纲和插入图片下方保留标题与列表层级。

## 1. 后续设计如何使用

1. 开始新增或修改界面前，先读本文、[动效规范](MOTION_GUIDELINES.md)、[视觉复查规范](VISUAL_REVIEW_GUIDELINES.md) 和 [UI 检查清单](UI_CHECKLIST.md)。
2. 优先使用现有样式变量、按钮和浮框组件。同一语义沿用同一颜色、图标、名称和交互。
3. 新增的公共规则同时更新本文、公共样式和检查项；页面特有布局写在对应组件附近。
4. 完成后逐项检查受影响界面，覆盖真实尺寸、缩放、长内容和交互状态。记录实际检查结果。

这是项目内持续维护的设计依据。具体参数由下列规则决定，参考产品只提供交互与层级上的借鉴。

赋予元素交互前，先明确它执行的动作与入口是否必要。品牌、标题和说明按内容呈现；具有实际动作的元素才使用按钮或链接，并提供对应反馈。

## 3. 字体、图标和间距

### 字体层级

使用系统界面字体栈，优先 Segoe UI、Microsoft YaHei UI、Microsoft YaHei。中文与英文保持共同基线。

| 角色 | 字号与行高 | 说明 |
| --- | --- | --- |
| 详情记录标题 | 24px，1.45 | 可换行，完整显示 |
| 页面标题 | 20–24px，1.4 | 与工具栏共同对齐 |
| 区块标题 | 14–16px，1.5 | 适度加粗 |
| 界面正文 | 14px，1.7 | 表单、说明、列表 |
| 详情长文本 | 16px，1.8 | 语音文本、摘要；按阅读宽度换行 |
| 按钮与输入 | 14px，20px | 相同控件层级统一 |
| 辅助信息 | 12／13px，1.5 | 只用于非主要内容 |

列表列只显示一行标题，垂直居中；超长标题省略并可通过提示或详情查看全文。卡片、整理结果中标题和摘要各占一行。详情正文和用户编辑内容自然换行，不使用固定高度截断。

### 图标

- 功能图标使用 Microsoft Fluent UI System Icons 的官方 20px 光学版本，Regular 与 Filled 使用分别设计的独立 SVG，常规按钮显示为 16px，操作栏显示为 20px。
- 图标来源固定为版本 `1.1.345`、提交 `9eb184e96268d3293462f9d9d19225b4c7b07774`。资源、原始许可证、来源及逐文件 SHA-256 清单保存在 `src/assets/ui-icons/`。
- 常规图标与文字间距 8px，录音面板的紧凑操作组使用 4px。图标居中对齐文字，内边距另行保留。
- AI 功能统一使用一个四角星，有文字时放在按钮内部的文字前。所有四角星按钮的线型、面型与文字使用墨绿 `#102719`，禁用时降低强调。
- 导航、文件夹、录音、播放、编辑、删除、更多操作使用对应的功能图标。短文本辅助动作可只用文字。
- 纯图标按钮提供明确的可访问名称，并为需要解释的动作提供提示。
- 纯图标按钮显式设置水平与垂直居中，包括“更多”和整理结果的叉号按钮。先核对图标框中心与实际底块中心，再按登记值检查图形光学偏移。
- 四角星是装饰标识，由按钮文字表达功能；装饰 SVG 对辅助技术隐藏。
- AI 标识分别保留官方两态 Sparkle 的主四角星，移除次星，并使用相同的居中视图框。保留原图和修改说明。

### 几何对齐与光学对齐

- 相邻外框与内部图片或面板共用对应角的圆心，均匀内缩量为 `g` 时，内圆角取 `max(0, 外圆角 − g)`。靠近外框角落的关闭按钮按实际悬停底块检查位置，底块半径采用公共按钮规格。正文与中部控件按内容基线对齐。
- 先建立每列的内容起线与区块边界。页面标题、工具栏、正文、来源和区块标题沿各自的公共起线排列；同级元素复用内边距。
- 同一行的文字对齐文字基线；按钮、输入框和复选框对齐控件中心。操作按钮将“图标 + 间距 + 标签”作为一组居中，保留既定点击范围。导航行、菜单选项和记录行按公共起线对齐，垂直居中，不改成整行水平居中。
- 几何检查使用控件矩形、字体与行高、公共间距；光学检查另看真实图形轮廓与文字的视觉重心。SVG 视图框居中只是起点。
- 图标同时检查点击框、16／20px 图标框和实际着色轮廓。播放三角形、非对称文件夹等形状需要时，可对图形做不超过 1 CSS px 的光学位移；默认位移为 0。
- 聊天品牌剪刀使用 20px 绘制框、36px 点击框，按实际轮廓与相邻录音／发送图形比较视觉大小，保持原位居中。
- 光学位移记录在共享图标规则中，注明语义、方向和原因。Regular／Filled 两态使用同一个校正参考，不随悬停来回跳；控件尺寸、标签位置、8px 间距与焦点框保持不变。
- 不通过给整排控件挪位置、改变点击框或强行拉宽图形补偿个别图标。更大的偏差先检查资产、视图框、字体和容器。
- 按 [视觉复查规范](VISUAL_REVIEW_GUIDELINES.md) 叠加起线、中心线与尺寸标记复查截图，再以实际尺寸人工判断疏密、重心和可辨认性。

### 功能图标的动效

- 应用绘制的可点击功能图标默认使用线型。悬停、键盘 `focus-visible` 或持续选中时，面型图案自下而上填充，时长 180ms。[聊天发送按钮](#聊天发送按钮)按草稿内容切换图标。
- 线型与面型使用互补的擦入／擦出区域：面型自下而上出现时，线型同步从相同区域退出。完成后只显示面型，避免完整描边叠在面型上形成模糊重影。
- 两态共用尺寸、基线和语义，过渡过程中保持控件和图标的位置不变；快速进出时从当前状态接续。
- 按钮持续选中时显示面型和选中底色，鼠标移开或键盘焦点离开后继续显示面型。取消选中且离开悬停与键盘焦点后反向恢复线型。分组收起等单次动作沿用悬停与键盘焦点反馈。
- 开启减少动态效果时立即切换线型与面型。普通不可用控件保持静止。
- 非交互装饰图标与非交互品牌 logo 保持静态；品牌录音控制按专用轮廓形变处理，用户指定的品牌剪刀按单次剪切规则处理。其余功能图标继续使用官方 Regular／Filled 擦换，原生窗口按钮沿用系统交互。

#### 聊天发送按钮

- 主窗口和浮窗的圆形发送按钮是图标动效例外。无可发送内容时禁用，在浅绿圆底上显示低强调的墨绿线型四角星。草稿有可发送内容时显示面型四角星，指针移开和键盘失焦后仍保持面型。
- 可发送内容包括非空白正文、图片、文件、可随消息发送的引用文字。空白字符和等待 Tab 采用的转写候选按空内容处理。最后一项可发送内容移除时恢复线型。
- 内容状态变化复用 180ms 双向擦换。减少动态效果时立即切换。录音、转写等临时禁用状态降低图标强调度，轮廓继续反映草稿内容。

### 间距与圆角

统一使用 `4 / 8 / 12 / 16 / 24 / 32px` 间距。控件内为 8–16px，同组控件间为 8px，区块间为 24–32px。

间距表达分组关系：同一组内部的行距、图文间距小于不同组之间的留白。小型录音面板沿用此层级，组内选项间隔约 4px，上下功能区之间约 8–12px；分别检查收起与展开状态。

- 普通按钮、输入框、选择器采用相同的高度和基线。
- 常规桌面控件高 40px；紧凑文字控件高 36px，整组一起调整。记录列工具栏采用最小 32px 的紧凑控件，具体内边距见导航列基准值。触控模式的目标尺寸至少 44×44px。
- 紧凑桌面图标按钮为 32×32px；操作栏图标按钮为 44×44px、图标 20px。高频独立操作和录音浮窗使用更大的点击范围。
- 点击区域与视觉控件边界一致，内边距属于点击区域；透明区域不覆盖相邻动作。
- 按钮底块采用公共 12px 圆角。输入框和选择器沿用各自圆角，播放器、截图等内容容器可采用 12px 圆角。

## 4. 导航与内容布局

主窗口由操作图标栏、分组栏、记录栏和详情区域组成。操作图标栏贯穿窗口，设置位于底部。录音说明仅从设置正上方的问号帮助按钮打开。帮助与设置按钮均为 44×44px，间隔 6px，设置按钮距栏底 12px。

最左栏上方依次为品牌、笔记和聊天，下方依次为帮助和设置。笔记是可见且常驻的返回入口，返回当前分组主页并保留聊天与输入。离开聊天时停止主动录音，已发起的转写可在后台完成。再次进入保留原会话。

分组栏的 InMoment 名称使用静态 `span`，保留标题栏拖动区域；不设置链接、点击动作、按钮式悬停与焦点，也不进入 Tab 顺序。返回分组主页由现有返回按钮负责。

分组栏顶部按文字行框组织间距，以下纵向坐标以分组栏顶部为 0，单位为 CSS px：

| 对象 | 容器与行框 | 文字行中心 |
| --- | --- | --- |
| InMoment 名称 | 标题区域高 40，文字行高 24，垂直居中 | 20 |
| “我的分组”标签 | 工具区内边距上下 12／左右 4，工具行高 32，标签行高 24 | 68 |
| 第一条分组名称 | 导航区内边距 0，分组行高 40，文字行高 24 | 116 |

创建表单收起且分组导航 `scrollTop = 0` 时，这三行文字的中心距为 48／48，24px 行框之间的空白为 24／24。文字节奏按行框与中心测量；按钮背景边界和外围留白另按控件规则检查。

分组栏标题行的内容间隔为 8px。有效视口宽度不超过 900px 时，抽屉标题行的水平内边距为 0，沿用分组栏自身左右 8px 的外部留白；保留 16px 品牌字号和 32×32px 关闭按钮，InMoment 完整显示。窄栏通过分配可用空间解决省略，字号和关闭按钮尺寸保持原值；上述纵向行中心不变。

- 分组主页提供卡片／列表切换，默认卡片并在本机记住偏好；未分类和其他分组使用同一入口。列表以紧凑单行标题为主，宽度允许时附带摘要与日期。切换只改变展示，不重置搜索、筛选、多选或记录操作。打开记录后，记录移入分组右侧的列表列，详情占据主要空间。
- 详情模式的搜索、筛选、选择和一键整理属于记录列表，集中在记录列顶部；加载反馈与重试同列显示，“加载更多”位于列底。右侧用于阅读和编辑当前记录。
- 记录列采用紧凑布局，可将“一键整理”和“添加到组”显示为“整理”和“分组”，提示及可访问名称保留完整动作。操作保持居中、可辨认，不能因列宽缩短而裁掉文字。
- 分组栏和记录栏等宽。在有足够空间的桌面窗口里，两栏加图标栏合计约占窗口的四分之一至三分之一。
- 操作栏宽 56px，分组栏与记录栏共同采用 `clamp(136px, 12vw, 232px)`。分组行高 40px，记录列表行高 52px。
- 每列独立滚动，列标题和内容拥有明确边界。长列表中的记录行不被挤压。
- 窄窗口或高缩放时分组栏改为可展开导航，详情模式继续保留操作图标栏、记录列和详情区。记录列顶部最多占列高的 60%，内容较多时自身滚动，为记录列表保留空间。
- 从展开的导航切换到另一页面时，沿用公共侧栏退场动效收起抽屉与遮罩，使目标页面立即可操作；同页刷新保留当前导航状态。
- 分割线表达实际内容边界。空区块不渲染，不连续堆叠分割线，也不在空内容上下各画一条线。
- 标题栏底部分割线连续延伸至窗口最右边，包括原生最小化、最大化和关闭按钮下方；普通窗口、最大化和页面缩放后均保持连续。
- 详情的滚动容器延伸到工作区右边缘，阅读留白放在内容内层；滚动条不受阅读宽度或外层内边距影响。
- 设置分类依次为「录音与截图」「AI 服务」「本地组件」「维护」。宽窗左侧显示分类，窄窗将分类置于内容上方。分类按钮用中性色三态，当前分类同时加粗。各分类复用同一表单，切换分类保留未保存修改。
- 设置内容独立滚动，保存栏在内容下方占用独立且不透明的布局行，保存按钮沿表单右侧对齐。滚到底可完整操作最后一项，点击与 Enter 均可提交。校验定位到有误的字段和所属分类。

### 导航列的基准值

以下横向坐标以记录列左边缘为 0，单位为 CSS px。公共内缩由 `--navigation-gutter: 8px` 提供。

| 对象 | 基准值 |
| --- | --- |
| 记录列顶部 | 顶部内边距 12；返回按钮的完整悬停底块距列顶至少 12 |

## 5. 旧记录详情的布局基准

详情按以下层级组织：

1. 记录标题与行末编辑入口；进入编辑后，标题原位替换为输入框，行末编辑图标替换为保存勾号与取消叉号。
2. “打开所在文件夹”、记录时间等轻量信息。
3. AI 总结与分组建议。
4. 同一个白底录音区域内的播放器、语音文本／思考摘要、文本编辑与本地转写入口，以间距组织。
5. 选区截图；背景信息包含来源应用、窗口标题、可打开的网址和自动获取的来源窗口截图。只显示有内容或有采集反馈的区块。
6. 其他低频操作。

### 播放器

- 播放／暂停、当前时间、总时长、进度和倍速共同形成紧凑播放器。
- 播放操作明确突出；音量与倍速属于辅助控制，保持对齐和相同控件尺寸。
- 进度可以拖动，也可以通过键盘调整。进度名称、时间与播放状态可被辅助技术识别。
- 多段录音属于同一条记录；每段使用相同结构，段号和时长轻量显示。切换记录时停止旧播放。
- 录音区域不绘制大外边框，音频片段不另铺浅灰卡片；播放器与文字直接位于白色阅读背景上，靠统一间距形成关联。
- 音频加载、无法播放、缺少附件各自给出明确状态；没有可用音频时保留文字阅读能力。
- 不使用虚构波形代表真实声音。没有波形数据时使用真实进度条。
- 回放波形由对应录音文件的真实采样峰值生成，未播放灰色、已播放绿色；显示按整段最大幅度归一化，保留相对起伏和静音零值。点击、拖动和键盘均可定位音频，时长、倍速和音量保持可用。读取时不阻止播放，切换记录与删除后旧结果不能回填；不支持的格式保留线性进度和明确状态。

### 语音文本与摘要

- 语音文本与播放器放在同一区域，查看文字时即可回听，不必跨过截图寻找录音。
- “语音文本”和“思考摘要”使用同一组切换控件；切换只替换阅读内容，播放器留在原处。
- AI 总结保留原文，摘要生成后可在同一区域切换查看。总结依据作为按需展开内容。
- 标题和“语音文本”的编辑图标统一位于各自行末。编辑时原内容直接替换为编辑框，勾号保存、叉号取消；标题支持 Enter 保存、Escape 取消，空白标题就地提示并保留编辑状态。
- 原文无论包含多少录音段，均以一个文本框原位编辑，保留全部文字、空行与换行；保存后按用户内容呈现，允许原文为空。该操作保留原录音及分段历史，不出现额外任务、分组或分段输入表单。并发修改先检查版本，取消只撤销当前编辑。
- 尚无摘要时给出当前可执行动作；尚无转写时允许补充文字或重新本地转写。

### 截图

来源信息、返回原窗口、图片预览及图片相关操作组成一个区块，内边距和按钮层级一致。

来源标签为透明背景。“回到原窗口”与来源放在同一轻量信息行；宽度不足时自然换行，并保持行内和行间间距。

记录标题下只保留“打开所在文件夹”这一项文件位置操作。截图的查看图片与打开图片所在文件夹服务于截图本身，放在截图区内。

## 6. 按钮、浮框和交互状态

| 状态 | 视觉与行为 |
| --- | --- |
| 未触发 | 透明底色，标签和图标清楚可见 |
| 预触发 | 指针悬停时叠加 4% 按钮基色，移开后恢复透明 |
| 触发 | 按下与实际选中使用同一 4% 底色，实际选中时移开指针仍保留。按下时在 90ms 内轻缩至 97%，释放后恢复原尺寸 |
| 键盘焦点 | 按钮底部短线可见，普通配色无围绕控件的描边 |
| 不可用 | 降低强调，禁止执行；悬停不改变背景、边框或图标，不显示按下效果 |
| 处理中 | 显示进度或动作状态，避免重复提交 |
| 失败 | 在相关操作附近说明原因与可恢复动作 |

### 每个按钮都检查完整底块

- 应用绘制的按钮底块以录音浮窗的圆角矩形为基准，文字、图文、菜单、列表和纯图标按钮共用 `--radius-button`（12px）。较小的按钮按可用尺寸收合圆角。聊天发送与停止回复采用同尺寸的正圆。侧栏按钮点击框外角为 16px，内缩 4px 后的可见底块为 12px 圆角。点击框尺寸与底块内缩分别验收。
- 整张网格记录卡片和媒体缩略图的点击面沿用对应内容圆角。卡片内的操作按钮使用公共按钮半径。原生窗口按钮沿用系统形状。
- 三态底色与按下动效适用于应用绘制的按钮，包括确认、取消和删除。前景色在三态间保持同一语义。输入框、复选框、开关、滑杆及选区使用对应的控件反馈。
- 保存／采用勾号使用公共 `ui-confirm` 绿色，取消编辑、取消录音与取消截图使用 `ui-cancel` 危险红色。关闭窗口、收起面板和普通预览关闭使用中性色。默认、悬停、焦点与禁用状态保持相同点击框。
- 为每个按钮确定点击框、背景边界、内容范围、内边距与外围留白。默认、悬停、按下、选中和键盘焦点分别检查同一套边界。
- 透明默认态预留完整的悬停与选中底块。底块靠近列顶、容器边缘或分割线时，以完整底块测量间隔。滚动容器内检查首项、末项和滚动后的键盘焦点短线，保持可见。
- 按钮标签独立居中，带图标时整组内容居中。常规操作按钮的标签或图文组距底块两端各至少 8 CSS px，同组相邻底块边缘间隔至少 8 CSS px。以原尺寸显出底块核对，另有规范的紧凑控件按各自尺寸验收。导航、菜单和记录行按公共起线排列。
- 当前页、选中的分组、笔记、聊天记录与设置分类持续显示触发态底色，悬停时沿用同一底色。单次动作在释放后按指针位置回到预触发或未触发态。展开属性表达面板的开合，持续底色需对应明确的选择。启用减少动态效果时即时切换底色并保持原尺寸。按下缩放作用于按钮绘制，排版按原尺寸计算。
- 主窗口 `summary` 折叠入口最小高 32px、行高 24px、内边距上下 4px／左右 8px，宽度为 `fit-content`。悬停和按下使用公共灰底，原生标记表达开合。
- 新增或修改按钮时，截图覆盖默认、悬停、按下、选中（适用时）和键盘焦点；结合禁用与处理中检查反馈、底块完整性和重心。细则见 [视觉复查规范](VISUAL_REVIEW_GUIDELINES.md#按钮各状态的底块与留白)。

### 操作与浮框

- 删除、添加到组、修改分组采用就近小浮框。浮框有边界和轻阴影，始终位于窗口可见范围内。
- 列表筛选统一从“筛选”按钮打开就近面板，集中放置时间范围、自定日期、关键词及“按描述查找”。“一键整理”保留在面板外，作为处理当前结果的动作。
- 面板显示当前分组范围，组合条件点击“应用筛选”后生效；取消或点击外部关闭时保留原有条件。“按描述查找”进入 AI 查找输入流程，输入文字本身不会发出 AI 请求。
- 已应用条件由触发按钮的名称、数量和提示共同表达。工具栏只保留一个筛选入口，后续同层条件复用此面板。
- 点击浮框外部或按 Escape 关闭。Escape 或选项操作关闭后将焦点返回触发按钮；点击外部时保留新目标的焦点。确认删除后才执行删除。
- 多选记录同时支持添加到组与删除；分组管理同时支持多选合并与多选删除。
- 记录多选工具栏使用透明底色；文字入口显示“选择”，进入后显示“完成”，入口本身不带线型图标。点击“选择”进入多选且初始选中 0 条；点击“完成”退出并清空选择。
- “选择／完成”的悬停与选中底块沿用自身最小 32px 高、上下 4px／左右 8px 内边距，文字始终在底块中央，与相邻复选框的对齐由外层布局处理。选择文字因内边距形成自己的起线，不加入搜索文字与记录标题的 40px 共线要求。
- 总选复选框常驻工具栏，与文字入口分开操作。未进入多选时点击复选框，直接进入并选择当前列表已显示的全部可选记录；进入后反映未选、部分选中和全选三态。部分选中时再点为全选，全选时再点清空。空结果或处理中按当前可用状态禁用。
- 总选入口由常驻复选框承担。复选框有独立可访问名称，部分选中通过原生 `indeterminate` 状态表达。“完成”切换按钮用触发态灰底表达当前模式，删除用危险红色前景。
- 卡片通过更多按钮打开动作，列表通过更多按钮或左滑呈现动作；相同行为使用相同图标与文字。
- 分组建议应用后保留当前详情和浏览位置，切换到其他记录或分组时再刷新归属显示。
- 分组建议按钮只显示组名：加入已有组用 `folder-in` 图标，创建新组用 `folder-plus` 图标。`title` 与可访问名称完整说明“添加到已有分组”或“创建分组并添加”，新建组仍需二次确认。
- 工具栏最多直接显示两个分组建议，其余收进“更多建议”小浮框。浮框支持搜索，长组名可查看完整名称，建议数量不会挤满工具栏。
- 一键整理只处理点击时当前筛选范围内的记录；结果按分组展示，每条记录可调整或取消归类。点击取消整理后直接停止并退出当前结果流程。

## 7. 录音浮窗与核心交互

首次长按右键开始录音，松开暂停；之后点击左侧播放图标免按录音，再点击同一位置的暂停图标暂停。所有片段属于同一份草稿。

- 录音状态、计时与主要动作形成稳定布局，状态改变时按钮不跳动。
- 保存使用确认绿色前景，删除使用危险红色前景，标签或图文组距各自底块两端至少 8 CSS px。继续与暂停图标沿用播放器图标风格。
- 录音胶囊用形态、时长和实际音量反馈状态，可访问名称说明暂停动作；展开面板为暂停、处理中、错误和不可用状态提供明确文字反馈。
- 调整外观时保持现有录音、完成和丢弃的时序与数据清理规则。
- 聊天与普通录音保存后的转写共用空内容语义：识别成功而某段只有标点／空白／符号时，移除对应录音片段并连续编号，转写失败不删除。保护此前有效文字及并发修改；已有旧记录仅在用户主动重新转写时应用该规则，不在启动时扫描删除。
- 右键长按与截图快捷键提供录音入口，聊天输入区提供语音输入，已有音频可从笔记背景信息播放。“录音说明”仅由最左栏设置上方的问号帮助按钮打开，提供“录音说明”提示与可访问名称。

## 8. 实现与复查

分组主页和详情模式复用同一份搜索、筛选与列表操作控件，切换时移动现有节点。保留输入内容、搜索焦点和选中文字范围；控件换位置时关闭旧浮框，重新打开后按新位置定位。控件移动本身不修改筛选、多选状态或未保存编辑，导航继续沿用原有确认和清理规则。

共享视觉值集中在 `src/shared/ui-tokens.css`，控件外观与图标动效集中在 `src/shared/ui-controls.css`，图标结构由 `src/shared/ui-icons.js` 提供。主窗口与录音浮窗共用这些组件。组件使用变量而非重复硬编码；修改公共值后同时复查各入口。通用图标通过 `data-ui-icon` 选择语义，复用线型与面型结构；四角星放在按钮内部、标签前方，保持原有可访问名称。

所有改变界面状态的交互都要匹配明确的反馈与过渡，按 [MOTION_GUIDELINES.md](MOTION_GUIDELINES.md) 选择类型。导航保留来源位置，浮层成对进入和退出，内容展开使用高度变化；拖动、滚轮、进度定位和文字输入即时跟手。共用实现为 `src/shared/ui-motion.js` 与 `ui-motion.css`。

网格卡片保留一致的预览高度。带截图时显示截图；没有截图时显示中性的语音或文本图标，使日期、标题和简要信息对齐。主页列表标题保持单行，辅助信息按可用宽度省略；详情记录列只显示一行标题。

每次界面改动运行本地检查，并按 [UI_CHECKLIST.md](UI_CHECKLIST.md) 验收布局和状态。布局测量后还要按 [VISUAL_REVIEW_GUIDELINES.md](VISUAL_REVIEW_GUIDELINES.md) 完成截图与人工复查，分别记录测量结果和视觉判断。真实 API 调用、录音和桌面截图仍遵循项目开发规则。界面测试使用隔离数据、合成音频和注入的模拟响应。
