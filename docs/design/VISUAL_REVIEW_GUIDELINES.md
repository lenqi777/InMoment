# InMoment 视觉复查规范

更新日期：2026-11-08。适用于主窗口、录音浮窗、设置、灵感云、浮框和弹窗。

视觉复查分两步：先量布局，再看实际画面。前者发现间距、尺寸、裁切和对齐问题，后者判断图标重心、信息层级、疏密与状态辨认。两类结果分别记录，公共参数沿用 [UI 规范](UI_GUIDELINES.md)，交互过程沿用 [动效规范](MOTION_GUIDELINES.md)。

## 1. 建立布局基准

每个页面先明确内容起线、列边界、文字基线与控件中心线。用这些基准组织内容，避免给每个元素单独补边距。

先检查元素的功能必要性：静态名称、标题与说明保持内容语义；按钮或链接对应明确的动作。分组栏 InMoment 名称是静态文本，检查其没有点击、链接、悬停底块或 Tab 焦点，标题栏拖动仍可用，返回入口由现有返回按钮承担。

| 检查对象 | 对齐基准 | 验收方式 |
| --- | --- | --- |
| 页面与列 | 列边界、公共内容起线 | 同列标题、工具栏、列表或正文沿对应起线排列；笔记页两列同高，笔记栏略宽。旧记录页的分组栏和记录栏等宽 |
| 同级区块 | 起线、宽度、上下间隔 | 标题、说明、表单和内容段落使用相同层级的间距 |
| 同行文字 | 文字基线 | 中文、英文、数字及不同粗细标签不出现忽高忽低 |
| 同行控件 | 点击框的垂直中心 | 同组按钮、输入框、复选框与选择器高度和中心一致 |
| 图标与标签 | 图标轮廓和文字的视觉中心 | 图标与 14px 标签搭配自然，整组内容位于按钮中央 |
| 按钮各状态 | 完整背景边界、内容范围和焦点外沿 | 透明默认态与悬停／选中底块共用同一空间，外围留白充足，状态变化不挪动内容 |
| 主窗口外壳 | 左栏宽、标题栏高、转角及内容区起线 | 两栏等宽高、同色、无交界线，内容区左上圆角统一；切换页面复核同一组坐标 |

布局使用 `4 / 8 / 12 / 16 / 24 / 32px` 间距。4px 用于紧凑内部关系，8px 为常用控件间隔，24／32px 区分内容区块。先使用公共 token；出现新值时说明对应场景，并复查同类控件。

文字按内容自然换行。记录列表只显示单行标题，网格卡片和整理结果的标题与简要信息各占一行；这些位置允许省略。详情标题、正文、编辑框、错误说明与确认动作完整可见。

创建表单收起且分组列表位于顶部时，分组栏顶部的三个文字行均为 24px 行高：品牌名称在 40px 标题区内居中，中心 y=20；工具区上下 12px／左右 4px 内边距、32px 工具行，标签中心 y=68；导航区内边距为 0，第一条 40px 分组行的文字中心 y=116。以分组栏顶部为原点，核对中心距 48／48 和行框空白 24／24，分别记录文字间距与按钮底块间距。

### 按钮各状态的底块与留白

检查按钮时，同步标出五项：点击框、完整背景边界、图文内容范围、内容到背景的内边距、背景到容器或相邻控件的外围间距。键盘焦点另标出轮廓外沿。按钮以实际着色的底块为视觉边界；复选框等控件保留“32px 点击框、16px 绘制框”的既定区别。

| 状态 | 截图与测量重点 |
| --- | --- |
| 未触发 | 底色透明。标出悬停时使用的完整背景矩形，确认空间已预留 |
| 预触发 | 悬停叠加 4% 按钮基色，移开后恢复透明。标签或图文组在底块内居中，四边内距符合组件规则 |
| 触发 | 按下与实际选中沿用悬停的 4% 底色，实际选中在移开指针后仍保留。对照默认态检查图标和文字的语义色 |
| 键盘焦点 | 图文位置稳定，焦点外沿及其间距在容器内完整显示，不被裁切或盖住 |
| 不可用／处理中 | 禁用或进度表现保留背景与点击框几何；禁用时悬停不改变底色、边框或图标，状态文字完整，不撑挤相邻动作 |

操作按钮以图文组的视觉中心对齐自身底块。纯文字按钮检查文字本身；导航行、菜单选项和记录行沿既定起线排列，垂直居中。分别检查汉字、英文和数字标签，结合字体基线与实际着色重心判断，避免只凭行高盒子认定居中。

测量组内留白时，用未缩放的悬停截图叠合相邻底块，沿其直边标出至少 8 CSS px 的边缘间隔。对常规文字或图文按钮，另标出图文组到左右直边各至少 8 CSS px 的内留白。点击框按各组件规格单独测量，按下时的 97% 缩放另外核对。

纯图标按钮分别测图标框中心和实际底块中心，横向、纵向误差各不超过 1 CSS px。检查“更多”与整理结果叉号等按钮的水平和垂直居中；图形自身的光学偏移按登记表单独复核，不能用它补偿整个图标框偏位。

分组滚动导航和选择浮框使用底部短线标示键盘焦点。滚到首尾并用键盘逐项进入，确认提示可见，文字、图标和边界保持原位。输入框的鼠标与键盘焦点均检查原边界和光标。

同一个按钮各状态使用相同的布局宽高、内边距、位置、圆角和标签基线。用同坐标截图叠合，比较背景四边与内容中心。在白底与浅灰侧栏上分别核对叠色。采样避开文字、图标、圆角抗锯齿边缘和键盘焦点短线。

| 基色 | 白底悬停、按下与选中约值 |
| --- | --- |
| 中性灰 `#191919` | `#F6F6F6` |
| 操作绿 `#256D49` | `#F6F9F8` |
| 危险红 `#B42318` | `#FCF6F6` |

聊天历史行按整块测量圆角和起线。分别悬停标题与更多按钮，沿行内直边检查底色连续，选中时对照相同位置的色值。两个入口的点击范围和键盘焦点分别核对。

按下检查 97% 缩放，释放复查原尺寸及底色。测试帮助、新建和分组收起的复位，以及当前页、分组和记录的持续底色。抽查删除、保存勾号、四角星、绿金品牌按钮与截图色样，比较实际画面和计算色值。图标的两态擦换沿用动效规范。

按应用按钮的可见底块验收公共 12px 圆角。将聊天加号、语音、剪刀的底块与录音动作底块叠合核对。发送与停止回复分别测量圆形底块直径、图标中心及与剪刀的间隔，核对切换时的位置。较小的按钮检查两端弧线完整。侧栏另量 44px 点击框和内缩 4px 的 36px 底块。分组、笔记、聊天用同一窗口尺寸叠合列边界，核对分组与笔记列标签的 18 CSS px、常规字重、文字起线和基线，并比较搜索框尺寸。核对启动首帧的笔记列为完整宽度，保持分组列开合状态时切组前后的列边界一致。选中态在实际尺寸复查浅底、正文及日期等次要文字的可读性。

记录列单独核对以下值：

- 顶部内边距 12px；返回按钮为 32×32px，完整悬停底块距列顶至少 12px，焦点外沿可见。
- 返回按钮底块右缘与分组标题之间留 8px，分组标题从列内 48px 起；搜索文字与多选记录标题仍从 40px 起。按控件边界保留间隔，不强行将这些文字排在同一起线上。
- “选择／完成”最小高 32px、上下内边距 4px、左右各 8px；文字在自身底块内水平和垂直居中。复选框位置由外层布局保持，选择文字拥有自己的内缩起线，不套用搜索文字与记录标题的 40px 起线。
- 默认、悬停、选中和焦点时重新测量顶距、底块内距与图文重心。窄列与 125%／150% 页面缩放重复检查。

全局复查覆盖最左图标栏、分组导航、记录列、网格动作、详情、播放器、截图工具、分组管理、灵感云、设置及浮框。各处使用同一套状态复查流程。

## 2. 图标的三层检查

图标有三个不同边界，复查时分别标出：

1. **点击框：** 紧凑图标按钮 32×32px，操作栏 44×44px，保持焦点和点击范围稳定。
2. **图标框：** 常规显示 16px，操作栏显示 20px，使用当前固定版本的官方 Fluent 20px 资源。
3. **实际轮廓：** SVG 路径或栅格化后的着色范围，含图形自身留白。用它判断图形看起来是否偏左、偏高或过重。

不同形状保留原有比例和留白。圆形、三角形与文件夹即使外框相同，视觉重量也可能不同；检查实际轮廓的边界和重心，再放回真实按钮判断。轮廓包围盒或像素重心是定位线索，最终以实际尺寸的画面为准。

Regular 与 Filled 必须是官方分别设计的资源，保持相同语义、尺寸和校正参考。并排查看默认线型、悬停面型、持续选中面型和动效中间帧，检查图形位置、轮廓清晰度与两态互补。鼠标和焦点移开后检查当前项的面型，切换当前项后检查前一项恢复线型。四角星两态和配套文字统一检查墨绿 `#102719`。

### 光学微调

- 默认偏移为 `(0, 0)`。仅在确有形状偏心时微调图形，单轴位移不超过 1 CSS px。
- 同一语义的两态共用偏移，在共享图标样式中记录。记录图标名、偏移、原因、检查尺寸和对应截图。
- 偏移只作用于图形；点击框、焦点框、标签、8px 间距与整行布局保持原值。
- 以 100% 实际尺寸判断效果，再放大检查边缘。125%／150% 复核时确认没有变成虚边、裁切或两态错位。
- 需要超过 1px 时，先检查资源、viewBox、遮罩定位、字体与容器。形状不同不要求填满同样的轮廓宽度。

### 当前光学校正登记

共享规则位于 `src/shared/ui-controls.css`，通过 `--icon-optical-x`／`--icon-optical-y` 移动图形层。下表记录 20px 图标、设备像素比 1.5 时的轮廓测量与实际画面判断；测量值已换算为 CSS px，正值表示向右或向下。

| 图标 | 观察与依据 | 共享偏移 `(x, y)` |
| --- | --- | --- |
| `play` | 包围盒水平中心约偏右 1.67，但 Regular／Filled 的着色重心仅约偏右 0.14／0.19；官方形状已做视觉补偿 | `(0, 0)` |
| `back` | 箭头的左侧重量表达方向；放回按钮判断，保留原轮廓 | `(0, 0)` |
| `folder-in` | 右下角动作标记使图形不对称；保留文件夹与标记的原有关系 | `(0, 0)` |
| `chevron` | Regular／Filled 的着色重心约向下 0.49／0.46，对两态共同上移半像素 | `(0, -0.5)` |

此表记录公共校正值及依据。后续更换资产、图标尺寸或字体时重新复查；非对称本身不是需要移动图标的理由。

## 3. 截图与测量步骤

使用独立测试资料库和合成音频，截图来自测试窗口自身。保留用户设置与记录，AI 状态通过注入响应展示。

1. **记录环境。** 写下应用版本、Windows 显示缩放、窗口内容尺寸、页面缩放、设备像素比和测试数据范围。截图像素换算为 CSS px 后再比较。
2. **截完整页面。** 覆盖主页网格、记录列表与详情、草稿、分组管理、整理结果、灵感云、设置、录音浮窗及受影响浮框。
3. **叠加基准线。** 在截图副本上标出列边界、内容起线、同行控件中心、文字基线及公共间距。对按钮增加背景四边、内边距、外围留白和焦点外沿，分别保存默认、悬停、按下与选中图。布局尺寸以 `getBoundingClientRect()` 等测量为依据。背景由伪元素绘制时，另量伪元素相对控件的位置。文字基线结合字体指标和截图检查。
4. **检查局部。** 保留一份 100% 图像判断实际观感，再放大图标、控件和文字相接的位置检查边缘。图标轮廓从路径边界或离屏栅格化透明度取得，不只读取 SVG 外框。
5. **回到交互。** 操作键盘、鼠标和滚动，核对焦点、可点击区域、悬停、动态变化及内容是否被裁切。动画同时检查开始、中间和结束画面。
6. **修正后对比。** 同一环境保存前后截图；公共样式变化同时复查主窗口与录音浮窗，确认共用控件仍一致。

同一环境中，原本共线、等宽或等高的元素，测量差不超过 1 CSS px；发现差异时先排除页面缩放与像素取整，再修正布局。这个容差用于定位误差，公共 token 仍使用约定值。

## 4. 尺寸、内容和状态覆盖

执行 [UI 检查清单](UI_CHECKLIST.md#窗口与缩放) 的六组窗口与缩放组合；大屏布局另查 2560×1400。普通窗口、最大化与缩放后都检查外壳转角、列宽和浮框边界。

每个共用控件至少覆盖默认、悬停、按下、键盘焦点、选中、不可用、处理中与失败。页面覆盖空结果、单条记录、多条记录、多个分组、长标题、长正文、多段音频、无截图和无摘要。

笔记格式及 AI 选区浮层复查保留浮层和选区首行，核对水平中心及上方 8px 间距。分别截取正文密集、选区靠左／靠右、顶部空间不足时的画面。检查格式浮层松手后 1 秒触发，滚动与缩放后按同一规则定位，正文保持原位。用按钮中心线核对图标两态与颜色圆点的位置，并核对默认色及换色后的圆点是否和菜单色样一致。媒体复查在同段保存左环绕和右环绕截图，量媒体宽度、邻接文字行框和边距。缩放、拖放、窄窗口及重开后分别核对可见布局与保存尺寸。

笔记编辑复查保留图片旁和图片下方的输入结果，以及跨图选区和粘贴后的画面。用隔离笔记和测试图片核对图文顺序、选区边界、光标位置与环绕。单图复制另查系统剪贴板的图片格式。标题 Enter 的焦点用实际输入位置复查，分别检查普通按键和输入法候选确认。

大图预览用混排截图和多栏图检查可选文字、整图及区域结果。比对适应窗口、放大和平移后的高亮位置。检查编辑工具的焦点与选中状态，窄窗下缩放、裁剪、旋转和复制操作可达，输出像素只包含原图范围和标注。

对照笔记、记录截图、主聊天与浮动聊天的共享大图工具栏。主窗口在普通与最大化状态检查右上角只显示预览的关闭按钮，标题栏与预览操作无交叠，关闭后恢复窗口控件。

参考图验收分别列出用户指定的形状／布局／交互范围和应保留的品牌配色、加载反馈与已有行为。录音复查同时覆盖可见水平长按进度、紧凑胶囊和展开面板。圆形 Logo 检查独立矢量路径与实际着色重心，不能以圆形容器居中代替字形居中。

录音圆形成为播放／暂停控制时，分别保留品牌、播放、暂停和形变中间帧。确认切口仍可辨认，两条笔画连续变化，圆形底和锚点不动。叠线图分别标出外框圆角与圆形的共同圆心、文字区靠内的公共起线。测量实际内容到左／底边界的空白与三行可见间距，再以实际尺寸人工判断疏密。对照问 AI、删除、存为笔记的三态截图，测量底块边缘间隔、两端内留白和共同圆角。

录音浮窗的位置检查使用真实原生窗口坐标，至少连续暂停／继续 20 次，覆盖准备、录音、暂停及重新显示；窗口与 Logo 无累积位移。只测渲染器内的相对坐标不足以证明屏幕锚点稳定。

胶囊进入聊天另存首帧、中间帧与终帧：首帧测量胶囊边框的屏幕坐标及外部透明像素，中间帧检查表面向右上扩展、文字字号与比例不变，终帧检查副本清理及默认未聚焦输入。点击编辑框后对照外框颜色、内层轮廓与阴影，确认只出现光标。检查提示与胶囊的独立留白、边缘工作区、关闭中断及减少动态效果。

紧凑聊天复查整窗四边、四角与内容的关系：前景边框连续，不被消息和输入背景覆盖，进入阶段不提前出现整窗轮廓。分别保存 Moment 左侧头像、用户右侧气泡、多行编辑、加号菜单和实时语音条。核对保存勾号与关闭相邻、动作基线、圆角层级及 440×560px 初始窗口是否被短内容意外放大。

在主窗口和浮窗的常规与窄视口检查右侧语音、剪刀、发送及其停止态的组内留白、底块圆角与点击命中。用 100% 实际尺寸复查疏密，并在 125%／150% 缩放下确认底块、标签和焦点短线完整。

发送按钮按[内容状态规则](UI_GUIDELINES.md#聊天发送按钮)复查。在同一窗口尺寸下保存空内容和有可发送内容的截图，核对浅绿圆底和图标中心。空内容时将指针移到按钮上，确认低强调的线型四角星保持静态。有内容时把指针与焦点移到别处，确认面型保持。再检查清空最后一项内容时的中间帧与线型终态，并开启减少动态效果复查即时切换。

聊天投影分别采样四边及底部的透明扩散区域，区分原生窗口边界与白色内容边界。圆角叠线标出外框 36px／输入框 24px／12px 留白的共同圆心。另量关闭按钮实际底块、图片附件与相邻外框的圆心，采用相邻圆角半径减内缩量的关系。对照主动录音开始前、录音中及停止后的截图，检查输入框、文字、附件和全部工具按钮的矩形与可见性，确认波形居中且为加号与录音间距的 80%，发送显示低强调的墨绿禁用状态。图片与文字间距约 8px，预览遮罩透明。右键菜单检查所选文字快照、多选双方消息及底部动作，状态成功后不产生输入上方标签。标题与原文编辑分别保存只读、编辑与保存后的画面，确认原位替换、行末勾叉和多段原文合为一个文本框。

截图编辑使用合成屏幕静帧检查框选、全部标注工具、撤销／重做与像素比例，确认导出仅含原图选区及标注，输出为单张图片附件。分别检查默认隐藏与保留当前页面、勾号与叉号恢复、会话关闭和迟到结果；测试不捕捉真实桌面。

截图录音分别保存标注区域、普通录音胶囊和暂停后的展开面板。测量拖动前后的浮窗坐标，验证透明部分可穿透到标注界面，关闭上滑问 AI 后无提示残留。核对勾号只提交一次合成截图并把同样的像素写入剪贴板。用合成静帧测试 Esc、单击和指针中断。

剪刀检查默认、剪切中间帧和终态，持续停留仅播放一次，移出再次进入可重播；聊天录音无圆底，录音胶囊保留原圆底。鼠标实际跨过按钮与顶层胶囊的空隙，检查返回、全移出 1 秒与键盘勾选。取消叉号与原加号点击框一致。

回放波形使用已知静音、脉冲和音量变化的合成音频，核对包络、已播放着色、鼠标拖动与键盘定位；多段和缩放不改变其他控件布局。切换或删除后的异步结果不恢复旧波形，复查不读取用户录音或调用转写模型。

最左导航复查笔记与聊天的选中状态、返回后的聊天内容，以及底部帮助与设置的 44px 点击框和 6px 间距。检查原麦克风位置的点击命中与 Tab 顺序。关闭浮窗再长按的验证不插入额外左键点击，只对隔离测试窗口发送合成输入。

聊天必须用真实键盘检查候选采用后的第二次 Tab、点击后再 Tab 和继续录音；不能只断言首次采用。用 2000 字、长英文／网址、多段换行与附件组合，检查候选和真实输入的内容高度、边框、工具栏、光标首尾与内部滚动。测试浮窗增高达到工作区上限后的布局，以及主窗口和高缩放下的受限高度。

自动审计记录所有应显示的控件，不能先剔除已经越界或被裁切的控件再计算通过率。滚动容器中的正常屏外项目单独验证滚动可达；当前应可操作的按钮则检查祖先裁切、真实命中和遮挡。页面没有横向滚动条不能单独证明内容没有溢出。

录音说明入口位于最左图标栏设置正上方，使用问号图标与“录音说明”名称。帮助与设置按钮均为 44×44px、间隔 6px，设置按钮距栏底 12px。验证鼠标提示、键盘进入及关闭后的焦点返回。录音回归覆盖右键长按、截图快捷键、聊天语音和历史录音播放。

记录选择工具栏重点检查：

- 总选复选框始终可见；点击可直接进入多选并全选当前列表已显示的可选记录。
- “选择”文字入口进入时选中 0 条，“完成”退出并清空；入口不带功能图标，也没有单独的“全选”按钮。
- 0 条、部分和全部选中的状态分别对应空框、混合态和勾选；混合态的复选框可通过键盘操作并被辅助技术识别。
- 空结果、加载或正在批量操作时，禁用与提示符合当前状态；分组、删除与计数随选择同步。
- 记录行、复选框及菜单不互相遮挡，Tab 焦点完整可见，点击空白和退出操作沿用当前选择语义。

使用 Tab／Shift+Tab 检查焦点顺序，Enter／Space 操作控件，Escape 退出浮框。减少动态效果开启时直接到达目标状态。检查快速开关、重复点击与中途切换页面后的最终画面。

## 5. 验收记录

复查记录包括：环境与场景、原图及叠线图、测量值、人工观察、修正内容和复查结果。脚本负责检查尺寸、溢出、状态属性和已编码的规则；人工复查负责判断信息层级、视觉重量、疏密和动效衔接。分别列出已检查与待检查的具体场景。

普通规范保留方法与标准，当次检查结果放在 `.local/` 复查报告中。后续修改重复使用这些基准，不将临时截图与本轮通过数量写成长期规则。

## 官方参考

以下资料提供对齐、适配与图标一致性的依据。4／8px 间距、1px 光学微调与截图验收步骤是 InMoment 的执行约定。

- [Apple HIG：Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：通过对齐与分组表达层级，使用布局导线，并在不同窗口和文字尺寸下预览。
- [Apple：Configuring and displaying symbol images](https://developer.apple.com/documentation/uikit/configuring-and-displaying-symbol-images-in-your-ui)：处理符号与邻近文字的基线、字重和比例关系。InMoment 将这些原则应用于 Windows 字体与 Fluent 图标。
- [Google Material Icons／Symbols 官方说明](https://github.com/google/material-design-icons/blob/master/README.md)：区分光学尺寸、字重与填充轴，并说明 20／24px 的像素网格设计。InMoment 延续 Fluent 图标族，借鉴其按使用尺寸检查的方法。
- [Microsoft Fluent 2：Iconography](https://fluent2.microsoft.design/iconography)：系统图标的语义、Regular／Filled 主题、尺寸选择与颜色对视觉平衡的影响。
