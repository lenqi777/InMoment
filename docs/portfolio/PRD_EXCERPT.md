# PRD 节选：从用户故事到验收条件

产品版本：v0.10.0｜对应主 PRD 文档修订：2｜更新日期：2026-10-17

这份节选选取录音、整批整理、阅读归组三组需求，保留[完整 PRD](../product/PRD.md)中的故事编号，展示“用户为什么需要—产品怎样决定—结果如何验收”。P0 指基本记录与资料管理，P1 指辅助理解与发现；优先级不代表开发完成状态。

要解决的问题是：收藏材料后容易忘记当时的联想，立即写完整笔记又会打断阅读。因此先把表达和触发情境留下，再回顾、整理与找回。当前依据来自个人体验和本地迭代，目标人群仍需外部试用验证。

## 1. 录音：一次表达对应一份草稿

**对应主 PRD：US-01–06、US-08（P0）。**

**用户故事（US-03）：** 作为需要停顿思考的使用者，我希望点击继续后持续录音，以便分几段说完同一个想法。

我保留首次长按来确认意图，之后用按钮控制续录。暂停不拆成新记录，保存与丢弃由使用者明确决定。

关键决策：

- 阈值前只显示判定进度，不创建内容草稿、不截图、不启用麦克风；提前松开，在适配范围内恢复普通右键行为。
- 首次录音松开暂停；点击“继续录音”后免按住表达，点击“暂停”结束当前段。续录不因右键松开而暂停，每次暂停释放本应用音轨。
- 所有片段共用一份本地草稿，续录保留首次来源。完成前不上传、不转写、不生成向量，也不进入正式搜索。
- 仅暂停时可完成；等待音频与附件收尾后提交一条正式记录。重复完成不重复保存，提交中或已保存内容不进入草稿丢弃流程。
- 丢弃先撤销回调与写入许可，再停止采集并清理截图、音频、元数据和临时文件；清理失败保留可见的待处理状态。

| 验收场景 | 预期结果 |
| --- | --- |
| 阈值前松开 | 不创建内容草稿、不录音、不截图 |
| 准备录音时已松开，麦克风稍后就绪 | 不启动迟到录音，释放本应用音轨 |
| 录一段、暂停、点击继续、再暂停并完成 | 只保存一条记录，可回听两段；续录期间松开右键不暂停 |
| 重复点击完成，或提交期间尝试丢弃 | 不重复生成记录，草稿清理不影响提交 |
| 丢弃后迟到的音频或截图回调返回 | 不重新生成记录；本次临时资料清理，失败可见并可重试 |

## 2. 整批整理：范围固定，分组经人确认

**对应主 PRD：US-17–20（P1），授权边界见 US-25–26（P0）。**

**用户故事（US-18、US-19）：** 作为批量整理资料的使用者，我希望只处理眼前这一批，并能按组检查、修改或取消建议，以便控制范围和费用，确认后再归组。

逐条建议组名容易产生零碎主题，所以先生成各条摘要，再比较本批成功摘要，提出共享分组。建议可以复用已有组、推荐新组，也可以保留未分类。

关键决策：

- 点击时固定当前实际显示的记录及版本，沿用分组、日期和查找条件；单次最多 100 条，后续导航不扩大范围。
- 请求数最多为本批条数加 1；统一归类使用本批标题、摘要与有限已有组名，原始音频不上传，截图辅助总结单独授权。
- 按“组—组内记录”预览，标题和简介各一行。每条可取消或修改，最终确认才创建或关联分组。
- 应用时重新核验内容版本，过期建议不能覆盖新编辑。采用后保持当前阅读位置，离开后再刷新原列表。
- 取消直接收起并停止后续请求，原始资料和已保存摘要保留；迟到结果不重新打开预览或应用分类。已发请求无法撤回，可能计费。

| 验收场景 | 预期结果 |
| --- | --- |
| 从 18 条中筛出 3 条后整理，中途切换页面 | 只有点击时显示的 3 条进入任务，新页面记录不加入 |
| 修改一条建议、取消另一条，再确认 | 仅按最终选择归组；取消项保留原记录与附件 |
| 等待结果期间修改记录 | 不应用旧版本建议，不覆盖新编辑 |
| 取消整理，或统一归类失败 | 原始资料和已保存摘要保留；取消后不再发起后续请求，失败原因可见 |

## 3. 阅读与归组：正文可读，资料关系可控

**对应主 PRD：US-09–15（P0），采用建议后的阅读位置见 US-19（P1）。**

**用户故事（US-09）：** 作为回顾资料的使用者，我希望按“分组—记录—详情”浏览，以便快速切换并把主要空间留给正文。

**用户故事（US-14）：** 作为已有多个组的使用者，我希望多选合并或删除组，以便整理分类结构。

关键决策：

- 进组先显示网格，打开记录后切为同组标题列表与详情。分组栏和记录栏等宽，详情占主要空间，列表与详情分别滚动。
- 窄列表标题一行，网格标题和简介各一行；长内容省略，完整文字、截图和原声在详情查看。摘要可切回语音文本，原始录音保留。
- 记录可以属于多个平行分组，未选组进入“未分类”；单条或多选添加到组保留已有关系，且不重复。
- 列表左滑、卡片菜单就近提供操作；分组选择可搜索，点空白或 Esc 可取消。合并成员去重，删除组只解除归属；删除记录另行确认并清理附件与索引。
- 用户修订优先于等待中的结果；归组后保持阅读位置，普通后台完成提示不长期占据正文。

| 验收场景 | 预期结果 |
| --- | --- |
| 多记录、多组、长标题，改变窗口与 125%／150% 缩放 | 规定行数可读，末项和按钮可到达；详情保留主要阅读空间 |
| 多选记录添加到组，或合并多个组 | 成员关系正确且无重复，已有归属与原始附件保留 |
| 删除一个组 | 记录和附件保留，无其他归属的记录回到“未分类” |
| 采用分组建议，或编辑期间后台结果返回 | 不打断当前阅读，不用旧结果覆盖新编辑 |

## 4. 授权、验证状态与下一步

云端默认关闭，各使用者在本机提供自己的密钥；发送前逐次确认，或明确开启“点击即发送”的持续授权。截图理解独立授权，原始音频和视频留在本地。云端不可用时，本地记录、回顾、普通搜索与手动管理仍可使用。

| 已有依据 | 尚待验证 |
| --- | --- |
| 录音状态、草稿提交与清理、授权、范围冻结、版本保护和分组管理已有自动回归；界面使用合成资料作隔离检查 | 真实宿主应用的右键兼容性、实际停止延迟及截图兼容性 |
| AI 流程使用模拟响应检查请求范围、取消、校验与部分失败 | 中文转写、真实摘要与分类质量、语义查找召回及实际费用 |
| 当前问题来自个人体验和本地迭代 | 外部使用者的任务完成率、找回耗时与整理修改量，尚无收益基线 |

下一步用固定样本和小范围任务观察建立基线，再确定效果目标；真实模型或 API 评测须另行明确批准。多人协作、跨设备同步、无限层级目录和全库 RAG 问答不在本版范围。
