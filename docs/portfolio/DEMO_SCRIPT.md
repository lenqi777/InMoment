## 画面与操作的关系

最前面先讲清右键录音：初次长按开始，松开暂停；点“继续录音”后可以放开鼠标表达，再点暂停。多次录音仍属于同一条草稿，点击完成后才进入灵感库。后半段依次展示回顾、归组、合并、查找与建议调整，让每个功能都有一个看得清的操作。

标签、引线和目标点只服务当前操作。目标关闭或动作结束前一起退出，下一镜头不保留上一镜头的标注。阅读与操作期间固定镜头，必要的平滑位移放在场景衔接处；音乐保持总时间线连续播放。
