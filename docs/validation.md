- 修正 pnpm 11 构建许可配置与测试发现目录；主进程 mock 集成与宿主网络开关隔离，应用本身的网络禁用保护保持不变。
- 在空目录及独立 pnpm store 安装锁定依赖，原生程序构建成功；独立源码检查通过。最终 `pnpm test` 为381项：380通过、1项显式桌面输入测试默认跳过，0失败。新增安装引导覆盖17个合成分支，不执行真实下载、安装或快捷方式操作。

- 最新完整包包含ASR、E5和53个生产依赖记录；模型哈希通过，在源码树外禁网络导入运行库成功，没有加载或执行模型。安装入口补齐系统VC++依赖检查、同意、固定官方下载校验及可见失败路径，未在开发机实际安装系统运行库。

- 公开演示导出为无音轨版本，保留原始音乐视频仅在本地。全新Windows系统实际安装、真实ASR/E5效果和DeepSeek云端端到端仍待授权后验收。本段结果不能替代这些尚未完成的验证。

## 退出错误回归

曾在退出后收到原生进程事件，导致控制器读取已关闭 SQLite，出现 `database is not open`。当前控制器先进入关闭状态、解绑自有监听器并等待音频与截图任务；主进程禁止关闭期间新增转写任务，取消现有任务后再关闭存储。单元回归与实际便携版退出均通过。

## 长按与命名回归

原生长按曾依赖 `GetAsyncKeyState`，但拦截的右键按下没有可靠更新该异步状态，导致阈值始终不能通过。当前按观察到的 DOWN/UP 事件与单调时间计时；短按回放、长按触发后松开、拖拽取消、配置更新、排除和禁用均已在自建隔离窗口通过真实 Win32 合成输入验证。生产程序不包含测试窗口或合成输入测试入口。

F8/F9/F10 使用独立键盘钩子，复用同一时序。默认检查覆盖配置、计时边界、重复键和修饰键状态；宿主应用的原功能键与菜单行为仍需试用确认。准备阶段的取消在每个异步边界重新校验，零延迟时同一批消息中的松开、丢弃或退出也不会启动迟到截图。

扩展键盘隔离回归时，测试窗口曾因对所有消息调用 `WParam.ToInt32()` 弹出溢出对话框。当前只在键盘消息中解析参数，以 64 位读取后取低 32 位；无界面回归覆盖高位和符号扩展参数。测试异常改为输出失败 JSON，不使用 WinForms 默认弹窗。正式打包的模块不包含该测试窗口。最后一次键盘桌面检查因 Windows 未授予前台而主动结束，F8/F9/F10 的真实输入兼容性尚未验收；没有重复抢焦点。

自动命名使用模拟模型响应验证：只处理正式记录，明确启用后每条最多一次，取消和删除后不写回；不覆盖手动标题或等待期间修改过的原话，旧表单中的空标题不清除后台新标题。真实 API 未用于这些测试。

## 离线速度观察

早期版本在本机一次处理约 11.9 秒合成语音耗时约 2.1 秒，耗时与音频时长之比约 0.18。音频由本机语音合成生成，属于英文合成内容；适配器使用默认中文解码。这只证明当次模型运行与处理吞吐，不能推断中文识别质量或其他设备性能。v0.7.0 已移除用户界面的处理详情，仍保留内部诊断数据。
