## Retained historical dependency notices

Original local packages using sharp 0.34.5/libvips 8.17.3 have a separate [Windows licensing README](docs/third-party/SHARP-WINDOWS-v0.34.5-README.md), [version inventory](docs/third-party/SHARP-WINDOWS-v0.34.5-versions.json), [Apache license](docs/third-party/SHARP-v0.34.5-LICENSE.txt), [upstream notices](docs/third-party/SHARP-LIBVIPS-v1.2.4-THIRD-PARTY-NOTICES.md), [component licenses](docs/third-party/image-libraries/README.md) and [libvips original LGPLv2.1](docs/third-party/LIBVIPS-v8.17.3-LICENSE.txt). Their fixed build source is [sharp-libvips 1.2.4](https://github.com/lovell/sharp-libvips/tree/20b5e899954907a3039d6e3d4c200aaa0ec52c4c). The source collection separates `sharp-0.34.5/` historical support from `sharp-0.35.5/` current support; they are not interchangeable. Dependency security and historical limitations are recorded in [the dependency review](docs/releases/DEPENDENCY_REVIEW.md).

Retained historical ASR bundles may also include SDL2 2.28.5, which is zlib-licensed; its [original release-2.28.5 license](docs/third-party/SDL2-2.28.5-LICENSE.txt) is supplied from [the SDL source](https://github.com/libsdl-org/SDL/tree/release-2.28.5). The current release preparation ASR allowlist excludes SDL2 and unused benchmark/server/llama tools; this SDL notice describes the unmodified historical packages.

Offline speech installation pins the original runtime asset and verifies its SHA-256 digest; the Whisper base model is verified against the model project's published SHA-1 digest. Semantic model installation pins all five files to one revision, verifies the two large files with SHA-256 and the three small files with Git blob SHA-1, and verifies them again when packaging. The semantic installer only downloads and validates files; it never runs a model. The explicit `--with-semantic` portable-build option copies only those files and their marker/license/provenance into `offline-semantic`. Models, runtime download archives, user settings, and generated recognition text are not part of the Git source tree.

## Portfolio demo production

Public release preparation uses a silent video and a GIF of the InMoment interface with synthetic example records and prepared AI results. Surrounding graphics and animation were created for this project. The original soundtrack-bearing MP4 remains a local working asset; a right to redistribute that soundtrack has not been established, so that file is excluded from the public source and release packages. The renderer uses local HTML, a browser and FFmpeg; no Remotion runtime or external template code is included. Motion research references are listed in [the video brief](docs/portfolio/VIDEO_PROMPT.md).
